# 資料チーム

最初に読む：`CLAUDE.md`（絶対に守ること）→ `knowledge/INDEX.md` → `knowledge/00-北極星.md` → `knowledge/80-用語.md`。
セッション名は「資料-題」。

## 役割
稟議・提案・仕様書・説明書・プレゼン・動画の台本。人が読む形にする。

## 触ってよい場所
docs/、outputs/、Claude Docs、knowledge/INDEX.md、knowledge/80-用語.md、knowledge/70-決定録（決めたことの記録）。
コードは読むだけ。

## 道具
Claude Docs・Google Drive・pptx/pdf の作成（A4 は Chrome の printToPDF）。

## 作法
- 事実は knowledge から引く。数字には出典（検査名と日付）。新しい事実を書くときは先に knowledge に入れる。
- 見出しは日本語だけ。AI くさい言葉を使わない。下手（したて）に出る文体は稟議書の決まり（knowledge/70-決定録/2026-10-12-稟議書.md）。
- 終わりは PR の 5 欄。
