**GitHub の読み書きは REST だけ**（このクラウドでは GraphQL が 403：`gh issue list`・`gh pr list`・`gh pr create`・`gh pr checks` は使えない）。`$R` を `repos/autumn07020/tube-schools` として：

- 開いている PR：`gh api -X GET $R/pulls -f state=open -f per_page=50 --jq '.[] | [.number, .updated_at, .head.ref, .head.sha, .title] | @tsv'`
- PR の検査：`gh api $R/commits/<sha>/check-runs --jq '.check_runs[] | [.name, .status, .conclusion] | @tsv'`。merge できる状態か：`gh api $R/pulls/<N> --jq '[.mergeable, .mergeable_state, .merged] | @tsv'`
- PR の中身：`gh api $R/pulls/<N>/files --jq '.[] | [.filename, .additions, .deletions] | @tsv'`（差分そのものが要るときだけ `--jq '.[].patch'`。大きければ先頭だけ）。本文：`gh api $R/pulls/<N> --jq .body`
- コメント（issue も PR も同じ口）：書く `gh api -X POST $R/issues/<N>/comments -f body="…"`、読む `gh api $R/issues/<N>/comments --jq '.[] | [.created_at, .user.login, .body[0:200]] | @tsv'`
- issue を作る：`gh api -X POST $R/issues -f title="…" -F body=@<ファイル> -f 'labels[]=<ラベル>'`。ラベルを足す：`gh api -X POST $R/issues/<N>/labels -f 'labels[]=…'`。外す：`gh api -X DELETE "$R/issues/<N>/labels/$(python3 -c 'import sys,urllib.parse;print(urllib.parse.quote(sys.argv[1]))' 対応中)"`。閉じる：`gh api -X PATCH $R/issues/<N> -f state=closed`
- 巡回（Actions）：`gh run list --workflow 巡回 --limit 3 --json conclusion,createdAt,url`
