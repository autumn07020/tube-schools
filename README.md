# Tube for Schools — プロトタイプ

早稲田アカデミー ロンドン校の生徒向け英単語・文法アプリ。
個人用アプリ「Tube English」の後継。

> **はじめての人は `SPEC.md` から読んでください。** 目的・現状・経緯・
> 踏んだ罠・残っている課題が1枚にまとまっています。本書は動かし方の手引きです。

- **全体像と引き継ぎ → `SPEC.md`**
- 企画と前身の経緯 → `HANDOVER.md`
- 作業時の決まりごと → `CLAUDE.md`
- 進捗を生徒ごとに分けて保存する設計 → `DESIGN.md`
- 運用設計（どこに置き、どう続けるか）→ `OPERATIONS.md`
- Gemini提案（Flutter/Firebase）の評価 → `REVIEW-tube-next.md`
- **セキュリティと個人情報の扱い（本番へ移す前に必読）** → `SECURITY.md`

> **`server/` は試用の道具であって、サーバではない。**
> ノートPCの中でしか動かず、TLSが無く、閉じれば止まる。
> **実在の生徒の氏名・連絡先・支払い情報を入れないこと。**

## 動かす

**このMacをサーバにして、ID・パスワードで使う**（推奨）。

```bash
cd "/Users/aki/Library/Mobile Documents/com~apple~CloudDocs/tube-schools/server" && python3 tube_server.py seed
```

アカウントとパスワードの一覧が表示される。**この一度しか表示されない**（保存されて
いるのはハッシュだけ）。控えたら起動する。

```bash
cd "/Users/aki/Library/Mobile Documents/com~apple~CloudDocs/tube-schools/server" && python3 tube_server.py serve
```

→ ブラウザで `http://127.0.0.1:8765/`

`seed` が作るのは、6クラス各3名（計18名）＋**講師8名**の26アカウント。
IDは `e5a01` `j1a01` `j3b01` … の形、講師は `teacher1`〜`teacher8`。
**講師はそれぞれ担当クラスだけ**が見えます（サーバが担当外を返しません）。

**このアプリは生徒の氏名を持たない。** 画面には `中2A-07` と出る。
誰がどのIDかは先生の手元の名簿で管理する（`SECURITY.md` 1章）。

アプリは起動時にサーバの有無を自分で確かめる。

| | 入口 | 記録の置き場所 |
|---|---|---|
| **サーバあり** | IDとパスワード | サーバ（端末を変えても続きから） |
| **サーバなし** | クラスコード＋名前 | その端末の中だけ |

サーバを止めても生徒の手元は壊れない。止まっている間の学習は端末に溜まり、
次に繋がったときまとめて送られる。

サーバを使わずに試すだけなら、静的配信でも動く（入口はクラスコードになる）。

```bash
cd app && python3 -m http.server 8765
```

| クラスコード | 小5 A | 小6 A | 中1 A | 中2 A | 中3 A | 中3 B |
|---|---|---|---|---|---|---|
| | `LDN-E5A` | `LDN-E6A` | `LDN-J1A` | `LDN-J2A` | `LDN-J3A` | `LDN-J3B` |

サーバ無しのときは**生徒だけ**が入れます（講師画面はサーバ経由のみ）。

## 講師に見せる（デモ公開）

Macで2つ動かすだけです。ルータの設定もポート開放も要りません。

```bash
cd "/Users/aki/Library/Mobile Documents/com~apple~CloudDocs/tube-schools/server" && python3 tube_server.py serve --demo
```

別のターミナルで:

```bash
~/bin/cloudflared tunnel --url http://127.0.0.1:8765 --no-autoupdate
```

`https://<ランダム>.trycloudflare.com` が表示されます。これを渡せば、
**Claudeを持っていない人でもブラウザだけで入れます。**

- サーバは `127.0.0.1` のまま。**Macにポートは1つも開きません**
  （トンネルが内側から外へ接続する）
- HTTPS込み。証明書の用意も不要
- `--demo` を付けると、ログイン画面に**押すだけで入れるボタン**が出ます
  （中身は `server/data/demo-accounts.json`）。**本番では付けないこと**
- URLは止めると消え、次回は別のURLになります
- Macがスリープすると切れます。別窓で `caffeinate -di`

見せ場（履歴・宿題・複数教科）は次で作り直せます。

```bash
python3 server/demo_seed.py
```

デモ（架空の校舎）の合言葉は、デモを作り直すたびに新しくなります。
**本物の校舎の席と合言葉は、管理ページ（`/admin`）で作ります**（`Claude outputs/手順-席と管理ページ（本導入）.md`）。
`passwd --all` は、管理者のいる本物の校舎では動きません（配ったカードを全部無効にしないため）。

## アカウントを操る

```bash
python3 tube_server.py list                          一覧と、保存済みの進捗
python3 tube_server.py list --csv                    表計算に貼れる形で
python3 tube_server.py add j2a04 04 --class j2a --level j2   ← 出席番号。氏名は保存しない
python3 tube_server.py add tanaka T9 --teacher --classes j1a,j2a   ← 担当クラス必須
python3 tube_server.py anonymise                     古い氏名入りデータを番号に置き換える
python3 tube_server.py passwd j2a01                  パスワードを付け替える
python3 tube_server.py passwd --all                  全員ぶんを作り直して一覧表示（デモだけ。管理者のいる本物の校舎では動かない）
python3 tube_server.py rm j2a01 --purge              消す（進捗も）
python3 tube_server.py seed --reset                  全部消してやり直す（デモだけ。管理者のいる本物の校舎は消さない）
```

パスワードを省くと自動で作られ、その場に表示される。
`--class` はクラスID。講師には `--classes` で担当を必ず指定する（既定で全クラスは見せない）。

保管の実体は `server/data/` にあり、バックアップはこのフォルダのコピーで足りる。

```
server/data/accounts.json        ID・パスワードハッシュ・所属
server/data/tokens.json          ログイン中の合言葉
server/data/assignments.json     宿題の指示（範囲・期限・対象）
server/data/audit.log            誰がいつ誰の記録を見たか（追記専用）
server/data/progress/<内部ID>.json   生徒1人分の進捗（宿題の達成もここ）
```

### この「仮サーバ」の限界

- **暗号化していない（TLSなし）。** 既定では 127.0.0.1 にしか口を開けない。
  `--host 0.0.0.0` でLANに開くと、入ったあとの印（トークン）と記録が平文で流れる
  （合言葉そのものは、入るときも流れない。`SECURITY.md` 8章）。手元の試し以外では開かない
- **本物の生徒の氏名や記録を入れない。** 動作確認のための道具である
- Macを閉じればサーバも止まる。IPは繋ぐ場所で変わる。常時運用するものではない

入れてある防御と、本番までにやることは `SECURITY.md`。

## 宿題を出す

講師で入って「宿題」タブ。教材・範囲・期限・対象を決めて出す。
**クラス一括でも、生徒を選んで個別にでも出せる**（誰も選ばなければクラス全員）。

ターミナルからも出せる。

```bash
python3 tube_server.py hw add "GRIT No.1000-1050" --from 1000 --to 1050 --class j2a --due 2026-08-07 --note "小テストは金曜"
```

```bash
python3 tube_server.py hw add "先週ぶん" --from 500 --to 540 --students j2a01,j2a03 --due 2026-08-04
```

```bash
python3 tube_server.py hw list      誰がどこまで終えたか
python3 tube_server.py hw rm <ID>   取り消す
```

打ち間違いは弾く（範囲が逆／1回500語超）。取り消しても**生徒側の達成記録は消さない**
――誤操作で努力を消さないため。

### アプリは単語を持たない

`Vocabulary GRIT 2500` のような市販教材は、語の選定・訳語・例文が編集著作物として
保護される（`HANDOVER.md` 4章）。だから**アプリが持つのは番号と達成状況だけ**で、
単語そのものは持たない。

生徒の画面には「No.1024」とだけ出る。冊子を見て思い出し、
**まだ / 覚えた / かんたん** で自己採点する。番号はそのまま忘却曲線に載るので、
一度「覚えた」を押した番号も、間隔をあけて確認に戻ってくる。

`app/content/manifest.js` の `booklets` に足せば冊子は何冊でも扱える。

### 生徒を動かす仕掛け

賞やランキングは置いていない。出すのは締切から逆算した数字だけ。

- **今日の目安** ―― 残り語数 ÷ 残り日数（下限は `hwMinPerDay`）。毎回やるたびに引き直す
- **残りと期限** ―― 「0 / 51語」「あと8日」「期限 8/7」
- **遅れの早期警告** ―― 予定線より落ちたら「今日◯語やれば追いつけます」。
  締切前日ではなく、落ち始めた時点で出す
- **期限切れでも閉じない** ―― 「いまからでも進めておくと先生に伝わります」と出し、
  やれば講師の画面に反映される

順位を出さない理由は、上位層には効いても下位層の離脱を招くため。
入れたくなったら `homeworkCards()` に足せる形にはしてある。

## 教材を足す（アプリ本体は触りません）

1. `app/content/<科目>/<名前>.js` を置く
2. `app/content/manifest.js` の `packs` に1行足す
3. 講師画面の「進度」で、その教材を学年に割り当てる

教材の書き方は2つの型だけです。理科でも社会でも同じです。

```js
// T（用語）  [表, 裏, 帯, 解説, 例, 例の補足]
["光合成","植物が光を受けて…つくるはたらき","基礎","行う場所は葉緑体。","",""]

// Q（選択）  [問題文, 正解, 誤答(|区切り), 帯, 解説]
["音の高さを決めるのは ___ である。","振動数","振幅|音速|距離","基礎","高さ＝振動数。"]
```

英語だけは専用の型（V=単語・P=語法・G=文法）も使えます。
`帯` の名前は教材ごとに自由です（英語はCEFR、理科は「基礎/標準」）。

**新しい科目を足すとき**は `manifest.js` の `subjects` に1行足します。
`code`（en / sci / soc）は項目IDの先頭に付くので、**一度決めたら変えないこと**。
変えるとその科目の進捗が別物になります。

## 進度を変える（講師が画面から）

講師で入って「進度」タブ。学年を選び、教科ごとに

- **つかう／つかわない** の切り替え
- **教材** の選択（複数可）
- **どこから やるか**（帯）
- **1日の量** と **復習の上限** を ＋ − で調整

保存すると `server/data/curriculum.json` に入り、その学年の生徒の画面に
すぐ反映されます。**担当していない学年は変更できません**（サーバが弾きます）。

## 検査する

目視で確認しない。アプリを開いた状態でコンソールに貼る。

```js
var s=document.createElement('script'); s.src='tools/check.js'; document.head.appendChild(s);
```

```js
await TubeCheck.all()
```

サーバ運用中は、検査用の資格を渡す（入口がID/パスワードに変わるため）。

```js
await TubeCheck.all({id:'j1a01', password:'…', teacherId:'teacher3', teacherPassword:'…'})
```

検査するもの:

- **死んだボタン** … 全画面の `button` / `select` を走査し、ハンドラの有無を確認
- **タップ領域** … 44×44px 未満を検出
- **保存6シナリオ** … 通常リロード／localStorage だけ失効／IndexedDB だけ生存／
  IndexedDB 不通／読み取りの一時失敗／空の書き戻し拒否
- **セッション通し** … 1日分を無人で走らせ、JSエラー0で完走するか
- **宿題カード** … 生徒の今日の画面に出ているか
- **教科** … その生徒に何教科わりあてられているか

2026-08-15 時点で全項目 PASS（サーバ運用・複数教科・宿題あり）。

## まだ無いもの（意図的に）

| | 理由 |
|---|---|
| 常時動くサーバ | いまは仮サーバ（このMacの中だけ・TLSなし）。本番構成は `DESIGN.md` 5章 |
| パスワードの自己変更 | いまは講師が `passwd` で付け替える |
| 宿題の締切通知 | 押し通知は入れていない。開いたときに出るだけ |
| 項目単位の同期の合流 | いまはブロブ単位。オフラインの取りこぼしが残る（`OPERATIONS.md` 5章） |
| 講師が単元テストを課す | いまは生徒が自分で「たしかめテスト」を押す形 |
| 受験用教材 | いまは IELTS 教材の流用。**英国綴り（realise / centre）のまま** |
| 発音・アクセント問題 | 受験固有。前身に無かった |

## 引き継ぐときに真っ先に決めること

1. **教材の方針** ―― 英国綴りを米国式に直すか。ロンドン在住の生徒なので、
   日常の英語と受験の英語が食い違う。`packs/core.js` の `B[]`（英国口語30項目）は
   既定のカリキュラムから外してあるが、削除はしていない
2. **中3の教材追加** ―― 上表のとおり1学期で尽きる
3. **常時動くサーバをどこに置き、誰が保守するか** ―― `DESIGN.md` 5章。
   いまの仮サーバはMacを閉じると止まる
4. **未成年データの扱い** ―― 12〜15歳。保護者への説明・保存期間・所在地を
   L2 に進む前に確定させる（`DESIGN.md` 5章）
