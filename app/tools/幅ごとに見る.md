# 幅ごとの崩れを見つける

崩れは「ある幅でだけ」出る。作っている最中の幅では出ないので、
目で見ている限り気づけない。

## iframe は使えない

`frame-ancestors 'none'` を返しているので、別ページに埋め込めない。
**この見出しは外さないこと。** クリックジャッキングを防いでいる。

## 代わりに、入れ物の幅を直に変える

このアプリの折り返しは、ぜんぶ `@container bento` で書いてある
（`@media` ではない ―― 左の柱があるせいで、画面の幅と中身の幅が
148px ずれるため）。つまり **入れ物を細くすれば、そのまま細い画面の
見え方になる。**

ブラウザの検査窓で:

```js
document.querySelector('#main').style.width = '390px';
```

戻すときは `= ''`。390 / 430 / 620 / 834 / 1024 / 1280 で見る。

見るところ
- 札の行に **空の枠**が残っていないか（歯抜けは「まだ何かある」と読まれる）
- 横にはみ出していないか（`document.documentElement.scrollWidth`）
- 文字が2行に折れて、隣の札と高さが変わっていないか
