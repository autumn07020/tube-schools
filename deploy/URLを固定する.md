# URLを変わらないようにする

## いま起きていること

無料の Quick Tunnel（`*.trycloudflare.com`）を使っている。これは
**切れるたびにURLが変わる**。実際、2026-08-18 の午前中だけで

    10:06  切断（半日そのまま。誰も気づかなかった）
    11:51  切断 → 張り直し → URLが変わり、配ったリンクが Error 1033
    11:55  張り直し

見張り（`deploy/run.sh`）を入れたので **止まったままにはならない**が、
URLが変わることは防げない。講師に配ったリンクは、切れた時点で死ぬ。

**これは設定の間違いではなく、無料版の仕様である。** 直すには、
自分の名前の付いたホスト名を使うしかない。

---

## 直し方は2つ。どちらも1回きりの作業

### A. Cloudflare の名前付きトンネル（費用ほぼゼロ・いま動いているMacのまま）

ドメインを1つ持てば、`tube.example.com` のような**変わらないURL**になる。
Mac は今までどおり動かしたままでよい。

必要なもの
  * Cloudflare のアカウント（無料）
  * ドメイン1つ（年 £8〜12 程度。`.com` や `.uk`）

手順（**ご本人の操作が要ります。**アカウント作成と支払いは代行できません）

    # 1. ブラウザで Cloudflare にログインし、ドメインを追加する
    #    （ドメイン業者のネームサーバをCloudflareのものに変える）

    # 2. このMacで、Cloudflareに紐づける
    cloudflared tunnel login

    # 3. トンネルを1本つくる（名前は何でもよい）
    cloudflared tunnel create tube

    # 4. ホスト名を割り当てる
    cloudflared tunnel route dns tube tube.example.com

    # 5. 動かす（deploy/run.sh の CF_NAME に名前を入れておく）
    CF_NAME=tube sh deploy/run.sh

これで `https://tube.example.com` が**ずっと同じ**になる。
切れても、張り直しても、Macを再起動しても変わらない。

### B. AWS などのサーバを借りる（月 $13 程度）

`deploy/README.md` と `deploy/deploy.sh` に手順がある。
固定IPと独自ドメインが付き、Mac を開いておく必要もなくなる。
校舎が増えるなら、いずれこちらになる。

## それまでの当座しのぎ

### 校舎の中だけで使う（Wi-Fiが同じなら、URLは変わらない）

    LAN=1 sh deploy/run.sh

`http://192.168.x.x:8765` のような、このMacのアドレスが出る。
同じWi-Fiにいる講師・生徒はそれで入れる。Macの再起動でも、
ルータが同じアドレスを配るかぎり変わらない。

**ただし暗号化されない。** 合言葉がそのまま無線に流れる。
デモの間はよいが、**本物の生徒の記録を入れたあとは使わないこと。**
そのときは A か B に移す。

### いまのURLを確かめる

**いちばん簡単なのは、`いまのURL.html` を開くことです。**

このファイルはプロジェクトの一番上（iCloud の中）にあり、
開くと**いまのURLへ自動で飛びます**。URLが切れて変わっても、
このファイルの中身は見張りが書き換えるので、開く場所は変わりません。

  * Mac … Finder で ダブルクリック
  * iPhone/iPad … 「ファイル」→ iCloud Drive → tube-schools →
    `いまのURL.html`。**お気に入りに入れておくとよい。**

講師にも「このファイルを開いてください」と伝えれば、
URLが変わるたびに配り直す必要がなくなります。
（ただし、同じ iCloud を見られる人にかぎります。
  全員に配るなら、やはりドメインを取るのが本筋です。）

端末で確かめるなら

    cat deploy/URL.txt

### 直したものを反映するとき

**`sh deploy/run.sh` を止めて起動し直さないこと。** トンネルまで
張り直され、配ったURLが死にます。サーバだけ入れ替えるには

    sh deploy/run.sh reload

トンネルは 127.0.0.1:8765 を見ているだけなので、その先を
差し替えてもURLは変わりません。

見張りが張り直すたび、ここが書き換わる。
これまでのURLの履歴は `deploy/log/url-history.log` にある。
