# 体制の始め方 ―― 本人がやること（2026-10-14）

段 0〜4 のうち、Claude が作れるものは置き場 `~/Projects/tube-schools` に入っています（Git 化・docs と outputs の整理・外部脳 knowledge/・5 チーム・番人・検査の workflow・routine の指示文）。
残りは GitHub と iPhone の口座が要るので、本人の手で順番どおりに進めます。合計 40 分ほど。

## 1. GitHub に私有リポジトリを作る（10 分）
1. github.com → New repository → 名前 `tube-schools`、**Private**、README や .gitignore は追加しない（空のまま）→ Create。
2. Mac のターミナルで：

```bash
cd ~/Projects/tube-schools && git remote add origin https://github.com/<あなたの ID>/tube-schools.git && git push -u origin main
```

   パスワードを聞かれたら GitHub のパスワードでなく Personal access token（Settings → Developer settings → Personal access tokens → repo）。SSH 鍵を登録済みなら `git@github.com:<ID>/tube-schools.git` でもよい。
3. `.github/CODEOWNERS` の `@OWNER` を自分の ID に置き換えて push：

```bash
cd ~/Projects/tube-schools && sed -i '' 's/@OWNER/@<あなたの ID>/g' .github/CODEOWNERS && git commit -am "CODEOWNERS に本人の ID" && git push
```

## 2. main を守る（5 分）
リポジトリ → Settings → Rules → Rulesets → New branch ruleset → 対象 `main`：
- Require a pull request before merging（Required approvals 1、**Require review from Code Owners**）
- Require status checks to pass（`サーバの検査・字・秘密・知識` を選ぶ。最初の push で Actions が 1 度走ってから出る）
- Block force pushes
Actions タブで「検査」が緑になるのを 1 度見る（Chrome の流れは PR と毎晩 3:00 に走る。初回が赤なら私に見せる）。

## 3. 外部脳を ChatGPT と Drive に（10 分）
- Google Drive：Claude が「TUBE study 外部脳」フォルダに `外部脳-全部.md` と `INDEX.md` を置く（置けなかった場合は `python3 scripts/brain/bundle.py` で `knowledge/_全部.md` を作って手で上げる）。NotebookLM に読ませるならこのファイル。
- ChatGPT：Project を作り、GitHub を接続して `tube-schools` の `knowledge/` を読ませる（接続できない場合は Drive の `外部脳-全部.md` を Project に入れる）。
- 写しの向きは Git → 写し の単方向。ChatGPT で決めたことは、本人か資料チームが `knowledge/70-決定録/` に書く。

## 4. 雲と iPhone（15 分）
- claude.ai/code を開き、GitHub の `tube-schools` を接続（初回は GitHub App のインストール）。雲のセッションで `/team-code 題` のように始められることを確かめる。
- 定期実行（routine）を 3 本作る：`knowledge/40-運用/routine.md` の指示文をそのまま貼る。巡回は毎晩 3:00、週報は月曜 7:00、拾うは 1 時間ごと。雲にデモの口座を置くかは本人の判断（置かないなら巡回は GET だけ）。
- iPhone：GitHub のアプリ（PR の承認と merge・Actions の結果）、Working Copy（1 行直すとき）、claude.ai（雲のセッション）。Remote Control は Mac が起きているときだけ。
- 1 日の形：朝 iPhone で issue（雛形あり）→ 雲が PR → 昼 iPad で approve → 夜 Mac で `sh deploy/更新.sh`。
