## 1. GitHub に私有リポジトリを作って送る（10 分）
1. github.com → New repository → 名前 `tube-schools`、**Private**、README や .gitignore は追加しない（空のまま）→ Create。
2. Mac のターミナルで（`<あなたの ID>` を置き換える）：

```bash
cd ~/Projects/tube-schools && git remote add origin https://github.com/<あなたの ID>/tube-schools.git && git push -u origin main
```

   パスワードを聞かれたら、GitHub のパスワードではなく Personal access token（Settings → Developer settings → Personal access tokens）。送るのは `main` だけ。
3. `.github/CODEOWNERS` の `@OWNER` を自分の ID に置き換えて送る：

```bash
cd ~/Projects/tube-schools && sed -i '' 's/@OWNER/@<あなたの ID>/g' .github/CODEOWNERS && git commit -am "CODEOWNERS に本人の ID" && git push
```

## 2. main を守る（5 分）
リポジトリ → Settings → Rules → Rulesets → New branch ruleset → 対象 `main`：
- Require a pull request before merging（Required approvals 1、**Require review from Code Owners**）
- Require status checks to pass：`サーバの検査・字・秘密・知識`（最初の push で「検査」が 1 度走ると選べるようになる）
- Block force pushes

Actions タブで「検査」が緑になるのを 1 度見る。「画面の流れ」は画面やサーバに触る PR のときだけ走り（約 30 分）、結果を PR に書く。必須にはしない。初回が赤なら、そのまま私に見せる（GitHub の Ubuntu では一度も流したことが無い）。
