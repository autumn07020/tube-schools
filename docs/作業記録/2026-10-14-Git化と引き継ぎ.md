## 7. 確かめていないこと・残っていること

- **GitHub Actions は一度も GitHub の上で流していない**（リポジトリがまだ無い）。Ubuntu の Chrome（`--no-sandbox`・`/usr/bin/google-chrome`・日本語の書体）は手元で確かめられない。初回が赤なら直す。

- 前半の置き換えで `CLAUDE.md` の中の画像・PDF・動画への道が `outputs/…` になったままの所がある（実物は iCloud の `Claude outputs/`）。

- 提案書にあった `scripts/brain/sync.py`（Drive への自動の写し）は作っていない。代わりに `bundle.py`（1 本にまとめる）と、Claude が Drive の道具で 1 ファイルずつ置く方法。
- PR に「main との写しの差分画像」を貼る仕組みは作っていない（流れの結果を PR に書き、写しを Artifacts に置くまで）。
- 無料の私有リポジトリでは、GitHub は main を守らない。守りは「本人が ✓ を見てから merge」と「Claude のセッションの番人」だけ。ChatGPT など Claude 以外の道具には番人が効かない（連携の権限を読むだけにするか、書ける道具には main に直接書かないよう指示する）。
