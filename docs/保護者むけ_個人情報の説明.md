# 学習アプリでお預かりする情報について

早稲田アカデミー ロンドン校 ―― 保護者のみなさまへ

---

## 結論から申し上げます

**このアプリには、お子さまのお名前を入れていません。**

生年月日も、ご住所も、電話番号も、メールアドレスも入れていません。
写真も、声も、位置情報も扱いません。

アプリの中にあるのは、**「中2A-07」という番号**と、
**その番号が何をどこまで解いたか**という記録だけです。

---

## 「名前を入れていない」の中身

「暗号化しています」「厳重に管理しています」という説明はよく見かけますが、
それは**入っているものを守る**という話です。私たちは、そもそも入れていません。

| よくある説明 | このアプリ |
|---|---|
| 個人情報を暗号化して保管しています | 個人情報を**受け取る仕組みがありません** |
| 厳重に管理しています | 管理すべき個人情報が**ありません** |
| 漏えい対策をしています | 漏れても**誰のものか分かりません** |

### 具体的に、何がどこにあるか

    アプリのサーバ（英国・ロンドン）
        中2A-07 は 単語を51語おぼえた
        中2A-07 は 8月18日に宿題を終えた
        ← これだけです。誰のことかは書いてありません

    校舎のNAS（早稲田アカデミー ロンドン校の中）
        中2A-07 は 〇〇さん
        ← お名前はこちらにしかありません

**この2つは別の場所にあり、別の人が管理しています。**
アプリのサーバには対応表がなく、対応表にはアプリのデータがありません。

---

## なぜ、この作りにしたか

学習アプリの情報漏えいは、実際に起きています。
そのとき何が流出するかは、**設計の段階で決まっています。**

もし名前を一緒に入れていたら、漏れたときに
「〇〇さんが、この問題を17回まちがえた」という情報が外に出ます。
お子さまにとって、これは成績表が公開されるのと同じことです。

名前を入れなければ、漏れても
**「ある番号が、この問題を17回まちがえた」**しか出ません。
それが誰かは、校舎のNASを別に破らないかぎり分かりません。

私たちは、**起きてから守るのではなく、起きても被害が出ない形**を選びました。

## ご確認いただけます

「名前を入れていない」は、口頭の約束ではありません。
仕組みとして確かめられるようにしてあります。

| ご質問 | 確かめ方 |
|---|---|
| 本当に名前が無いのですか | 校舎で画面をお見せします。生徒の一覧に出るのは番号だけです |
| 入力する画面はないのですか | ありません。名前を入れる欄そのものが存在しません |
| 名簿を読み込むときは | お名前の列があるファイルは、**取り込みが拒否されます** |
| 誰が見られるのですか | 担当の先生だけです。他のクラスの先生には表示されません |
| 見た記録は残りますか | 残ります。「いつ・誰が・どの番号を見たか」を記録しています |

第三者の技術者にご確認いただくこともできます。
検証用の手順書（`DPIA.md` 付録）をご用意しています。

## お子さまが使うとき

### ログイン

先生からカードをお渡しします。2行だけ書いてあります。

    ID       lj2a07
    あいことば  maple-1360

**このIDとあいことばは、お名前とは関係のない、でたらめな組み合わせです。**
生年月日や電話番号から作っていません。

### 使う端末

- 小学生 ―― ご家庭のパソコン、または iPad
- 中学生 ―― それに加えて、ご本人のスマートフォン

アプリを入れる必要はありません。ブラウザで開くだけです。

### 広告について

**広告は一切表示しません。** 広告会社にデータを渡すこともありません。
アプリは外部にデータを送らない設定になっており、
これはブラウザの仕組み（Content Security Policy）で機構的に制限されています。

### 順位について

**点数や順位は表示しません。**
順位を出すと、下位のお子さまが学習をやめてしまうためです。
表示するのは「何日続いたか」だけです。

## 情報の保管期間

**ご退塾から6か月で削除します。**

- ご退塾のご連絡をいただいた時点で、ログインを停止します
- 記録は6か月残します（お戻りになる場合、続きから始められるようにするため）
- 6か月を過ぎたら、記録を削除します
- バックアップからも、その後30日以内に消えます

## よくあるご質問

**Q. 先生は、うちの子の成績を全部見られるのですか**

担当のクラスの生徒だけです。他のクラスの先生には表示されません。
また、先生が個別の記録を開いたときは、その事実が記録に残ります。

**Q. 開発した方は、中身を見られるのですか**

技術的には、サーバの管理者としてアクセスできます。
ただし見えるのは番号と学習記録だけで、**どなたのものかは分かりません。**
お名前との対応表は校舎のNASにあり、開発者はアクセスできません。

**Q. 使わせたくない場合は**

これまでどおり、紙の宿題だけで進めていただけます。
アプリは補助であって、必須ではありません。
使わないことでお子さまが不利になることはありません。

**Q. 途中でやめられますか**

いつでもお申し出ください。ログインを停止し、6か月後に記録を削除します。
すぐに削除をご希望の場合も、お申し出いただければ対応いたします。

**Q. 学校（早稲田アカデミー）とは別の会社なのですか**

このアプリは、講師である（氏名）が個人で開発・運営しています。
早稲田アカデミーとは業務上の取り決めのうえで提供しています。
