# 法の 3 枚（下書き。2026-12-15 までに仕上げる）

## 0. 前提（第 5 版の作りから）
- 持つデータ：アカウントの ID（無作為の番号）、単元、入れた問題の数と自分の答え、当てた型の番号、戻りの日の正誤、日付。**氏名・学校名・写真・音声・自由な文章は持たない。** 試しの段では外の AI（LLM）に何も送らない。
- 置き場：端末の中（記録の同期を付けるなら英国か EU のサーバ。日本は英国の十分性規則の対象だが、受け手の要件があるので第一候補にしない。補完-10）。
- 試す相手：本人の担当の小 5（校舎の生徒）か、校舎の外の家庭。どちらでも書面の許可と、雇用条件の本文の確認が先。

## 1. DPIA（データ保護影響評価）の骨
| 項目 | 書くこと |
| --- | --- |
| 目的 | 子どもが自分の間違い方を見て直す練習。学力の推定・順位・プロファイリングはしない（Children's Code 標準 12。既定で切のまま） |
| 扱うデータ | 上の 0。個人を特定する項目は無い。アカウントの ID と保護者の連絡先は別の台帳（校舎か保護者が持つ） |
| 法的根拠 | 保護者の同意（13 歳未満は保護者の許可。16 歳未満も保護者の同意の画面を通す） |
| 保存 | 記録は端末の中。同期する場合は 12 か月。退会で消す。測定用の録音は作らない（第 5 版は音声入力なし） |
| 共有 | 外の AI 事業者には送らない（試しの段）。外の評価者には型の番号・正誤・日付だけを匿名で渡す |
| 子どもの意見 | 作る前の 10 分（紙の台本）の無記名の 1 問と、匿名フォーム（標準 2 の「子どもと親の意見」） |
| 年齢に合った作り | 画面の言葉は小 5 向け。保護者向けの全文と、子ども向けの短い説明を分ける（標準 3・4） |
| 設計の既定 | 通知・引き延ばし・ご褒美・順位なし。1 回 8〜12 分で終わる。時間の上限（DfE の基準） |
| 危険 | 「間違い方を当てる」が外れて子どもを責めたと受け取られる → 「たぶん」の言葉と「当たらない」の扱い（単元の練習へ） |
| 見直し | 2027-02 と、英国の弁護士の確認のあと |

## 2. AI 事業者と保持の条件
- 試しの段（2026-12〜2027-02）：外の AI を使わない。この欄は「該当なし」。
- 本番で通訳（打った短い言葉を決まりに訳す）に LLM を使う場合：13 歳未満のデータは OpenAI がゼロ保持を先に求める。Anthropic は未成年向けの追加の指針が条件。Gemini は旧規約で 18 歳未満向けを禁止（現行は未確認）。→ 使うなら Anthropic か、端末内の小さなモデル。保持は 0 日、学習に使わない契約。保護者に「何を送るか」を 1 行で示す。

## 3. 16 歳未満の保護者の同意の画面（文面の案）
1. 見出し：「お子さんが使う前に、保護者の方に確かめていただくこと」
2. 何をするか：「間違えた問題の数と答えを入れると、どんな間違い方かを機械が当てて、別の数で走らせて見せます。答えは教えません。」
3. 何を持つか：「持つのは、アカウントの番号・単元・入れた数と答え・当てた型の番号・正誤・日付だけです。お子さんの名前・写真・声・文章は持ちません。外の AI には送りません。」
4. どこに置くか：「お子さんの端末の中です。消すときは設定から消せます。」
5. 誰が見るか：「保護者の方と本人だけ。塾で使う場合は、残っている × と消えた × の数だけが塾に渡ります。」
6. 同意：「上を読み、お子さんが使うことに同意します」（保護者の確認。生年月日は持たず、年齢の区分だけ）
7. やめ方：「いつでもやめられます。やめると記録は消えます。」

## 4. 試す相手の書面の許可（校舎の生徒で試す場合）
- 宛先：校長（本部の許可が要るなら本部）。本人の雇用条件の本文（知財・兼業・競業）を先に読む（本人の作業。12 月中）。
- 中身：目的（直しの新しい形の試し）・期間（12 月後半〜1 月の 4 週）・人数（小 5 の 5 人）・持つデータ（上の 0）・校舎が受け取るもの（点検の札と月 1 行だけ）・やめ方・本人の立場（塾の名でなく本人の試作）。
- 校舎の外で試す場合：家庭との同意（3）だけ。校舎の名を使わない。

## 5. 本人にしかできないこと（12 月中）
1. 雇用条件の本文を読む（知財・兼業・競業の条項）。
2. 校長に、紙の台本の 10 分（5 回）と、5 人の試しの許可を書面で求める。
3. 英国の弁護士の 1 回の確認（DPIA と同意の画面）。費用は未調査。
