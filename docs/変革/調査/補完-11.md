# 補完-11 競合：AI に教える製品と研究

調査員の記録。判断はしない。検索は WebSearch 27 回・WebFetch 11 回（2026-11-04）。読むだけ。**公式ヘルプ・リリースノートを直接読めたものは少なく、多くは検索の要約と二次情報**。確認の強さは表に書く。推測は（推測）。

## 要約

- **「子ども（9〜15 歳）が AI の生徒役に教える」を核にした市販製品は、今回の検索では日本・英語圏・中国・韓国のどこでも見つからなかった。** 見つかったのは、(a) 大人・大学生向けの「AI に説明して理解を確かめる」アプリ（Feynman AI・Teachback・Feynman Apprentice）、(b) 大学向けの「Teach the AI」課題（Packback）、(c) 研究用の試作（Curiosity Notebook・AlgoBo/TeachYou・Chat Melody・生成 AI の teachable agent）、(d) 子どもが「ロボット／分類器」を教える製品（Pika・LittleAIMaster。教える中身は「AI の仕組み」や色・絵の認識で、教科学習ではない）。
- Khanmigo・Duolingo・Quizlet・ChatGPT 学習モード・Gemini Guided Learning・Claude 学習モードは、検索の範囲では「生徒に教えさせる／AI が生徒役」を名乗る機能は確認できなかった（公式ヘルプの全文は未読。「無い」の断言はできない。4 章）。
- 日本（スタディサプリ・進研ゼミ・atama+ ほか）と中国（作业帮・猿辅导・学而思・豆包爱学）は、AI が教える・質問に答える・採点する方向の説明ばかりで、「子どもが AI に教える」は見つからなかった。中国語圏では「AI に学生役をさせる費曼学習法」のプロンプト例が多数あるが、これは利用者が自分で書く使い方で、製品の機能ではない。
- 韓国：Miraen「チョコ」の「概念カード」が「言葉で説明する勉強法」に近い（AI が生徒役かは未確認）。QANDA に該当機能は見つからず。
- 研究で最も近いもの：Song ら 2024（6 年生 108 人・中学数学・生成 AI の teachable agent、知覚の調査。効果量なし）、Chen ら 2024（ChatGPT を tutee に・プログラミング・大学生）、Chat Melody 2025（大学生 28 人・音楽・η²p = 0.35）、AlgoBo/TeachYou（大人 40 人）。**子ども × LLM の生徒役 × 学習効果の測定は、今回の検索では見つからなかった**（総説 2025-11 も「小学 STEM の teachable agent の実験は限られる」）。
- 効き目の証拠：古典（Betty's Brain・Chase 2009）は小中学生で「教える立場だと努力が増える（protégé effect）」と、教えた群が教わった群より伸びた。メタ分析（Kobayashi）は「教える前提で学ぶ／教える」の効果が g = 0.27〜0.56 程度。子どもの教えるロボット実験（2025）では先行知識が低い子ほど効いた。**LLM が生徒役のとき「賢すぎて教える必要が無い」問題**が複数の研究で出ている。
