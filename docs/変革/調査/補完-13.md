# 生徒役 AI と音声の実現性と費用（補完 13。調査員の報告。判断はしない）

見た日はすべて 2026-11-04。検索 約 30 回・頁の読み取り 6 回。読み方：技術の棚卸し.md は冒頭、補完-8.md は要約と表、補完-7.md は見出しだけ読んだ（重複を避けるため）。法の英国側（Children's Code・DfE）は補完-8 に詳しいので、ここでは音声・API 規約・製品例だけ足した。為替は 1 ドル＝150 円で換算（推測の前提）。料金の多くは第三者の集計頁で、公式頁は Anthropic だけ確認できた。確度の欄：高＝公式か原典、中＝複数の二次、低＝単独の二次・要確認。

## 要約
- 生徒役：「プロンプトで新米のふりをさせる」だけでは専門家の知識が漏れる、と複数の論文が報告している（2026 年）。対策は 教わった内容だけを渡す境界づけ・知識の消去（unlearning）・誤りの型を持たせる、の 3 系統。**日本語・子ども相手での実測は見つからず、自前の試験が先に要る。**
- 子どもの音声認識：英語では子どもの誤り率は大人より大幅に高い（大人 約 3％ に対し子ども 約 25％ という引用）。子どもの音声で調整するとかなり下がる。**日本語の子ども音声の誤り率の数字は見つからなかった**（古い論文に「低年齢ほど悪い」の記述のみ）。
- 費用（1 人・月 500 分）：音声 API 直結は 約 $6〜90（約 900〜13,500 円、モデルと会話の持ち方で桁が変わる）、テキスト LLM＋端末内の音声認識は 約 $1〜18（約 150〜2,700 円）、端末内 LLM は変動費 0。
- 端末内 LLM：Apple の約 30 億パラメータのモデルは日本語対応・文脈 4,096（iOS 26.4 以降は 8,192 の報告）。日本語の生徒役の品質を測った報告は見つからなかった。
- 法：OpenAI の API は 13 歳未満の個人データを「ゼロ保持の設定」なしに処理しないよう求める（公式）。Anthropic は 18 歳未満が使う製品に追加の指針を求める（公式）。Google の Gemini API は 18 歳未満が使いそうなアプリを禁じる（旧版の規約。現行は要確認）。米国 COPPA は子どもの声の録音を「返事のためだけに使い、すぐ消す」なら同意なしで可。日本は 2026 年改正で子どもの規律が入った（細目は未確認）。
