# 錯題本と適応学習（調査 2026-11-04）

見た日はすべて 2026-11-04。WebSearch の要約を主に使い、頁そのものを読めたのは Khan Academy の効果報告と間隔反復の比較頁だけ。数字の多くは会社の自己申告で、各行に区別を付けた。推測は（推測）と書く。

## 要約
- 中国では、間違いを写真で取り込み、類題を出す機能は、拍照搜題・学習機・错题打印机の標準装備になっている（事実）。ただし「それで成績が上がった」という第三者の検証は、見つけられなかった。
- 中国の錯題本が大きくなった理由は、機能より販路にあった（推測）。拍照搜題の無料の集客 → 学習機・打印機の販売、という筋。2021 年の規制で拍照搜題が名指しされ、事業が硬件へ移った。
- 日本・英米の適応学習は、何を適応させるかで 3 つに分かれる。(a) 単元のつまずきをさかのぼる（atama+・すらら・Qubena・ALEKS）、(b) 記憶の間隔を決める（Monoxer・Anki・Duolingo・Quizlet）、(c) 会話で導く（Khanmigo）。どれも「紙の宿題」とは接続していない（確認できた範囲）。
- 第三者の厳密な検証があるのは少数。知的指導システム全体のメタ分析（効果量 0.4〜0.7 前後）と、間隔反復の予測精度の公開ベンチマークだけが、会社から独立した裏付けだった。atama+・すらら・Monoxer・Qubena は自己申告か導入先の公表値。
- 日本の中学受験向けの錯題本アプリは、見つからなかった（「無い」と書く）。近いものは、写真から暗記カードを作る汎用アプリと、「忘却曲線で間違いを再出題する」歴史・地理・漢字のアプリだけ。算数・国語の誤答から類題を作る仕組みは、見つからなかった。
- 模倣の難しさは、アルゴリズムではなくデータと内容にある。忘却モデルは公開され（FSRS・HLR）、誰でも使える。残るのは「教材の中身と単元の地図」「間違い方のデータ」「紙の答案を読む入口」（推測）。

## 声になっていない兆し
事実：
- 紙の答案を読んで、錯題を拾う入口（拍照）は中国で実用の域にあり、日本の塾向けにはほぼ無い（今回の検索の範囲）。
- 日本の適応学習は「アプリの中で解く」前提で、塾の「紙の宿題」と接続したものは見つかっていない。
- 第三者の厳密な検証が少なく、塾にとっては「効く」と言いきれる根拠が乏しい。

推測：
- 紙の宿題の誤答を、講師が何もせずに拾い、次の宿題・小テストに戻す回路は、日本の中学受験には空白（推測。検索の範囲が狭く、塾内の私的な道具は見えない）。
- 忘却モデルは公開されているため、アルゴリズムの優位は長く続かない。差になるのは、受験の単元の地図・誤答の型の分類・講師が付ける評価という、現場でしか集まらないデータ（推測）。
- 錯題本の効果は「間違いの理由を考える」行為にあり（D6）、機械が代わりに整理すると効果が消える恐れがある（D4 との合わせ読み。推測）。
- 中国の例が示すのは、機能より集客と販路の強さが勝敗を決めたということ（推測）。個人の講師が同じ道を行くには、集客の入口が別に要る。
- 海外在住の家庭は帰任の時期が直前まで分からず（本人の答え）、帰国後の 8 割は国内の同じ塾に戻る。個人ごとの誤答の記録を帰国時に渡せるなら、他の誰にも出せない書類になる（推測）。
