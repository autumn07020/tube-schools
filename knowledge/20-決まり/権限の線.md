# 権限の線（変えない）

2026-09-24、Claude が本番サーバに SSH でログインし本人の Safari を操作しようとしたことは「既に規約違反レベル」と裁定された。以後の線：

- **本番サーバへの SSH・scp・rsync は、どのチーム・どのセッションからも絶対にしない。** 本番に対して行うのは GET と、デモの入口で選んだ生徒として入ることだけ。wt01 や本物の講師では入らない。
- **本番反映（`deploy/更新.sh`）・ためしのデモ（`deploy/ためしのデモ.sh`）・デモの作り直し・本番切替・時間割と担当の投入は本人が流す。** Claude は命令文を渡すだけ。2 回以上リトライしない。将来の案B でも承認は本人の指だけ。
- 本人の画面・Safari の操作はしない。2026-10-09 の緩和：画面の確かめのために手元の Chrome／WebKit（wk.py）／iOS シミュレータは使ってよい。必要最小限の操作（見る・押す・撮る）だけ。
- 作業ディレクトリの外で読んでよいのは `~/myAcady/demo-accounts.json` だけ（書かない・写さない）。鍵・認証情報は読まない。
- `../myenglish/`（前身 Tube English）は変更しない。
- `合言葉の表.nosync/`（iCloud の tube-schools）は読まない・送らない・写さない。Git にも Drive にも入れない。検査で突き合わせるときも合言葉を画面に出さない。
- `scripts/accounts/make.py` は二度と流さない（表とサーバが食い違う）。足し引きは管理ページ（/admin）。
- サーバに生徒の氏名・住所・電話・連絡先を置かない。市販教材の中身を置かない。本部のシステムに触れない。`カリキュラム/時間割.csv`・`時間割.json`・`時間割の講師.csv`（講師の名字入り）は本番へ送らない・Git にも入れない。
- 巡回は 1 回 10 万トークン以内。同じ動作を繰り返さない。サブエージェント・Workflow・並列のエージェントは、見積もりを示して了承の後だけ。
- 止める合図は `巡回を止める.txt`（置き場の直下）。

## 仕組みで守る
- `.claude/hooks/guard.py`（PreToolUse）：本番への ssh/scp/rsync、make.py、合言葉の表、deploy/*.sh の実行、myenglish と demo-accounts.json への書き込みを止める。手で確かめる：`echo '{"tool_name":"Bash","tool_input":{"command":"sh deploy/更新.sh"}}' | python3 .claude/hooks/guard.py`。
- `.claude/settings.json` の permissions.deny（ssh・scp・make.py・合言葉の表・myenglish・deploy/accounts）。
- `.gitignore` と `scripts/check/secrets.py`（pre-commit と GitHub Actions）：合言葉・鍵・本物の束・名字の表を履歴に入れない。
- `.github/CODEOWNERS`：担当外の変更は PR でそのチーム（いまは本人）の承認が要る。
