## 巡回
- **毎晩の巡回は GitHub Actions の `.github/workflows/patrol.yml`（2026-10-20 夜。本人「クラウドで毎晩、検査だけ」）**：04:00 UTC（ロンドンの冬時間 4:00・夏時間 5:00。S3 の控えの 3 時と重ねない）に、GitHub の Ubuntu が `scripts/check/expect.py --base https://tube-study.uk` を流す。読むだけ。入るのは GitHub の Secrets `TUBE_DEMO_ACCOUNTS_B64`（`deploy/demo-accounts.json` の base64）にある架空のデモ校の口座だけ。秘密が無ければ口座なし（門の検査だけ）で流し、そう書く。控えは `scripts/check/ledger-production.json` の写しに書き、合言葉が記録に混ざっていないことを機械で確かめてから、expect.log と ledger.json を Artifacts「巡回の記録」に 14 日。失敗なら issue「巡回 YYYY-MM-DD：失敗」（最後の行・× と △ の行・実行への link）。月曜に通れば控えを今日の数にする PR「巡回 YYYY-MM-DD（週の控え）」（枝 `patrol/ledger-YYYY-MM-DD`。GitHub の設定で Actions が PR を作れなければ issue に JSON を貼る）。定期の実行は main の patrol.yml で動く。別の枝で試すのは Actions → 巡回 → Run workflow（枝を選ぶ）。結果は実行の Summary にも出る。
- 止める合図：置き場の直下の `巡回を止める.txt`（iPhone の GitHub からでも置ける）。2026-10-07 から置いてあったが、10-20 の本人の決定で消した。Actions の巡回も、このファイルがあれば何もせず緑で終わる。
