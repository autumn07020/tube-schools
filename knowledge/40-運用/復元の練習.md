# 復元の練習

**なぜ**：稟議書と「情報セキュリティ対策」に「試行期間中に復元の練習を 1 回」と書いた（法務 #4 の 10 番）。UK GDPR 32 条 1 項 (c)(d) は「障害のあと速やかに個人データへのアクセスを回復できること」と「その手段を定期的に試すこと」を求める。試したことのない控えは控えではない（`deploy/backup-setup.sh` の末尾）。

**何をするか**：本番には触れない。S3 の控え 1 本を**本人の Mac** に戻し、手元でサーバを起こし、機械で確かめる。全部 `deploy/復元の練習.sh` がする（本人が流す。Claude は流さない）。

## 前提（練習の前に 1 度そろえる）
- `~/Projects/tube-schools`（置き場）で `python3 --version` が 3.11 以上。
- `aws` CLI（`brew install awscli`）と、本人の AWS の鍵（`aws configure`。S3 の控えのバケットを**読める**権限。サーバの IAM ロールは PutObject だけなので、読むのは本人の鍵）。
- `deploy/demo-accounts.json`（手元だけのファイル。架空のデモ校 london の口座。意味の検査が入るのに使う。無ければ門の検査だけになる）。
- 控えのバケット名と、戻す日付：`aws s3 ls s3://<バケット>/ | tail -3`（毎日 03:00 UTC に `YYYYMMDD-HHMMSS.tar.gz`。30 日で消える）。

## 手順（番号順に 1 行ずつ。本人の Mac で）
1. `cd ~/Projects/tube-schools && git pull`
2. `aws s3 ls s3://<バケット>/ | tail -1`（きのうの控えの名前を見る）
3. `sh deploy/復元の練習.sh s3://<バケット>/<日付>.tar.gz`（取る → 展開 → 中身を数える → 手元で起こす → 意味の検査 → 新しい口座 → まとめ）
4. 出た「記録に写す行」を、下の表に貼る（PR か、Mac の Claude に頼む）
5. `rm -rf 復元.nosync/<日付時刻>`（戻した中身には本物の口座の検証子が入っている。残さない）
6. 画面も見たいときは `KEEP=1 sh deploy/復元の練習.sh …` → `http://127.0.0.1:8960/demo` → 見終わったら `kill <番号>`（まとめに出る）

## かかる時間
- スクリプトそのものは **1〜3 分**（手元の土台で 13 秒：取る 0・展開 0・数える 0・起こす 1・意味の検査 7・新しい口座 5。本番の控えは数十 MB なので S3 から取るのに 1 分ほど足す）。
- 練習として枠を取るなら **30 分**（前提をそろえる・読む・記録を書く・消す まで）。
- 本番へ本当に戻すときは **30〜60 分**（下）。

## 戻せたと言える条件（スクリプトが機械で確かめる。1 つでも落ちれば「戻せていない」）
1. **展開して、校舎が 2 つある**（`london`＝デモ、`waseaca-london`＝本物）。口座の数・宿題の数・提出の数・最後の記録の時刻が出る。最後の記録が控えの日時に近いこと（「控えの新しさ」が 1 日前後）。
2. **意味の検査が通る**：`scripts/check/expect.py` を、戻した置き場に当てて流す。前回の本番の数（`scripts/check/ledger-production.json`＝巡回の控え）と比べて **△ 0・25% 以上減った数が無い**。つまり、戻した置き場は本番と同じ中身で、画面の目的（成績のコース・次の授業・人数・写真の段階）を満たす。
3. **新しく作った口座に、今週の宿題が見える**：戻した置き場に中3R の口座を 1 つ作って入り（SCRAM）、期限前の宿題が 1 件以上届く（`join_open_homework`。CLAUDE.md 絶対に守ること 7）。本物の校舎で「表面だけ」でないことを確かめる印。

## 本番へ本当に戻すとき（記録が壊れた・消えたときだけ。本人だけ。障害時の手順書の 4）
1. 先に今の状態を退避：`ssh ubuntu@<静的IP> 'sudo tar -czf /tmp/before-$(date +%Y%m%d-%H%M).tar.gz -C /srv myacady'`
2. 上の手順 1〜3 で、戻す控えを**まず手元で確かめる**（3 つの条件が通る控えだけを本番へ）
3. `aws s3 cp s3://<バケット>/<日付>.tar.gz .`
4. `ssh ubuntu@<静的IP> 'sudo systemctl stop myacady'`
5. `scp <日付>.tar.gz ubuntu@<静的IP>:/tmp/`
6. `ssh ubuntu@<静的IP> 'sudo tar -xzf /tmp/<日付>.tar.gz -C /srv && sudo chown -R myacady:myacady /srv/myacady && sudo systemctl start myacady'`
7. `curl -s https://tube-study.uk/api/health` → `{"ok": true, …}`。続けて `python3 scripts/check/expect.py --base https://tube-study.uk --accounts deploy/demo-accounts.json --ledger /tmp/ledger.json`
8. 校舎に伝える：控えの時刻（03:00 UTC）より後の提出・評価・登録は失われている。その日の宿題は紙で受けてもらう。
9. 記録（下の表と、`障害時の手順書.md` の 7）

## 注意
- **本番には触れない。** 練習は Mac の中だけ（127.0.0.1:8960）。戻した置き場は `復元.nosync/`（`.gitignore` の `*.nosync/`。iCloud にも入らない）。終わったら消す。
