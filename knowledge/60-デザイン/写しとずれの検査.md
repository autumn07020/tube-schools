# 写しとずれの検査

## 写し
- 4 つの役（小学生 le4b01・中学生 lj2r01・講師 lteacher1・管理）× 3 幅（電話 390・iPad 820／768・PC 1440）を全部回す。iPhone だけにしない（本人「pc 版もね」）。
- 道具：`scripts/check/shots.py`・`scripts/check/atlas/`（画面台帳）・`tour_*.py`・`pairs.py`（見本と写しを左右に）。写しは `TUBE_BROWSER=webkit`（Mac だけ。Chrome では出ない崩れが出る）。
- 画面を変えたら 3 つのブラウザで流す（`20-決まり/検査の流儀.md`）。

## ずれ（2026-10-11 の叱責「px 単位での調整になっていないか」「2 桁以上を想定していない」）
- `adm_flow15.py`：講師・生徒の全画面 × 6 つの幅で、横はみ出し・窓の外・親からのはみ出し・重なり・小さい押し場所を数える。84 画面すべて 0 件にしてから報告する（svg の中は見ない・動きを止めてから測る）。
- 直し方は入れ物の決まり：溝と札の高さをそろえる、縦の塊は flex-start、列は幅から（auto-fill minmax）、名前がぶつかる class は改名、長い字は min-width:0＋ellipsis。
- 数字は桁で小さく（`countUp` の `data-len`、輪は `ringC`）。新しい数字の枠は 3 桁と「10/10」で確かめる。
- 列の見出し（導入と進度のはしごの言葉）は行と同じ grid-template-columns と同じ余白で置く。言葉の高さは「2 行ぶんの箱で下そろえ」、説明は幅があるときだけ（container query）。古い CSS の grid-area の名前が残ると新しい格子で列の外に出る。縦長の一覧は 1280px から 2 列（行の数で半々）。
- 文字を枠に合わせる所（登録コード 6 桁）は letter-spacing で 1 つの欄を枠に見せない。1 文字ずつの枠（flex で真ん中）＋透明な入力欄を重ねる。検査は `adm_flow16.py`（枠の真ん中からのずれを px で数える。全画面の動画は占有率 100%）。

## 宿題チェックは 1 画面に（2026-10-11）
- ≥700px：`fitCheck` が左右の高さを画面の下までに決める。右の紙は写真が残りを全部（`object-fit: contain`、縦横どちらも）。評価・理解が心配・ひとこと・添削のボタン列は 1 行ずつで常に見える。`#main` の下の余白は iPhone 用の 120px でなく 16px。
- 数で確かめる：`adm_flow13.py`「ページが縦にスクロールしない」「写真 ≥ 画面の高さの 4 割」「評価・ひとこと・添削が見えている」。写しは Chrome と WebKit、PC と iPad の両向き。右の紙に行を足すなら写真から取らずに何かを消す。
- 添削（ペン）：ペンだけを受け付ける。指は「指でも書く」を押したときだけ。ペンの直後 1.5 秒は手のひらを無視。
- 時間割（PC）：週を 1 つの格子に（列＝曜日 `--d`、段 `--r`）。

## 今日やることの札の密度（2026-10-11）
- 札の塊 `.t-cards` は折り返す flex。1 枚の幅は列数 `--cols` から calc、`flex-grow: 1` で余りが行を埋める。JS は枚数の印（`n3`・`n6`・`n9`）を付けるだけ。nth-child や JS の last で「最後の 1 枚」を見分けない。
- 列数：電話 1→2、700px〜 2→3、1024px〜 2→3（10 枚以上は 4）、1440px〜 2→4。小さな札は 1 行。12 枚まで（13 枚以上は 11 枚＋「ほか N 件」）。検査は `adm_flow14.py`。
