# 2026-09-24 権限の線

- 経緯：Claude が本番サーバに SSH でログインし、本人の Safari を操作しようとした。本人「既に規約違反レベル」。
- 裁定：A 本番 API をデモの合言葉で読むのは許可（読むだけ）／B 本番への SSH は絶対ダメ／C 本人の画面・Safari の操作はダメ／D `~/myAcady/demo-accounts.json` は読んでよいが、その外に絶対に進まない／E iCloud への写しは現状どおり／F 巡回は定期実行で新規作成して自律的に回す。サブエージェント禁止。無為な作業でトークンを浪費しない。毎回同じ動作をしない／G 1 回の巡回は多くても 10 万トークン。アイデアと閃き・提案と実行・反省と自己改善に多くを当てる。
- 10-09 の緩和：「実際にブラウザや iOS シミュレータを用いることも許可する。必要最低限以上の操作は厳に禁ずる」。
- 2026-10-14：線を仕組みにした（`.claude/hooks/guard.py`・permissions.deny・secrets.py・CODEOWNERS）。本文は `20-決まり/権限の線.md`。
