# 2026-10-12 稟議書

- 原本：https://claude.ai/code/artifact/5dd8f2ee-3988-4105-8864-9fd12d550b47（Claude Docs。図 2 枚は widget）。印刷用 A4 は `outputs/稟議書/`（HTML → Chrome の printToPDF。本文 11pt 1 枚＋別紙の図 2 点）。Docs 自体の PDF 書き出しは 4 ページになるので使わない。
- 形式は Google Classroom の稟議書（件名・起案日・1 結論〜8 依頼事項・Before/After 表）。A4 片面 1 枚・11pt・冗長な表現を削る。
- **決めたこと**：費用は「サーバー費・維持費 月額 £110（月額で確定）、人件費は応相談」。起案者は空欄。**11 月**から試運用。講師の希望制。オンライン授業と土曜授業から。連絡は Classroom、宿題と記録は TUBE study。現状はオンラインの生徒が relation で送り、印刷 → 添削 → コピー機でデータ化 → メール返却。
- 文体は下手（したて）に出る提案。クレーム対策は「やめる・紙に戻す」と書かない：「各講師が適切な時期に、理想と考える方式でオンライン提出と紙提出を切り替えている」と保護者への案内に明記する。
- 個人情報の欄：招待リンク → 学年・受講教科・受講クラスだけ入力 → ID と合言葉を設定 → ID がクラスに紐づく。名前と紐づかないまま宿題提出・添削を受けられるのがサービスの根幹。
- 直すときは Docs の原本と HTML の両方を揃え、ページ数が 2 のままか確かめる。
