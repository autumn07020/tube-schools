# 2026-10-22 PHP と Node.js の脆弱性の点検

本人の指示（10-22、運用の routine のチャット）：「php と node.js の深刻なセキュリティリスクが報告されました。確認した上で、弊サイトに関与する可能性がある部分全てをチェックし、アップデートせよ」。

## 報告されたもの（2026-10-21 公表）
- **PHP**：CVE-2026-109618・CVE-2026-109619（通称 php2shell）。CVSS 9.2。未認証の遠隔コード実行と、PHP のワーカーのメモリの読み出し（合言葉や API の鍵が漏れうる）。php-fpm・mod_php・php-cgi・FrankenPHP・LiteSpeed が対象。直った版は 8.5.12・8.4.27・8.3.36・8.2.35。公表の 4 日前（10-17）から攻撃の試みが観測されている。CISA が即時の更新を求めている。
- **Node.js**：10 件（高 4）。最も重いのは CVE-2026-111497（Brotli の復号で範囲外の書き込み → 遠隔コード実行。fetch() と Express 5 が Brotli を自動で復号するので届きやすい）。ほかに TLS のホスト名の確かめの迂回が 2 件（CVE-2026-106069・CVE-2026-105483）、dns.resolve が NUL で名前を切り詰める（CVE-2026-105482）、randomUUID の種が起動の写しに残る（CVE-2026-106074）。直った版は 22.23.4・24.22.1・26.12.1。**20 以前（EOL）には修正が出ない。** 同梱の根証明書も更新（eMudhra の中間 CA の侵害）。

## 決めたこと
- **GitHub Actions の部品を Node 24 で動く版に上げる**：checkout@v5・setup-python@v6・upload-artifact@v6（それぞれの `action.yml` の `runs.using: node24` を 10-22 に読んで確かめた）。checkout は v6 にしない（v6 は保存する認証情報の置き場を変える。巡回の月曜の PR が `git push` に使う）。入力の形はどれも前と同じ。
- サーバ・画面・deploy には変えるものが無い（PHP も Node も無い）。
- 本番の OS の更新は apt。Ubuntu のクラウドの像は unattended-upgrades が既定で入り security を自動で当てるが、`deploy/aws.sh` は明示していないので、動いているかは本人が確かめる（下）。

## 本人の手（番号順に 1 行ずつ。本番は読むだけ、更新は本人の判断）
1. 本人の Mac から、いつもの手順で本番に入る（鍵は Mac だけ）
2. `dpkg -l | grep -E -i '^ii +(php|nodejs|node|npm|libnode)' || echo 'php/node なし'`
3. `command -v php node nodejs npm || echo 'php/node なし'`
4. `sudo apt-get update -qq && apt list --upgradable 2>/dev/null`
5. `systemctl is-enabled unattended-upgrades; systemctl is-active unattended-upgrades; cat /etc/apt/apt.conf.d/20auto-upgrades`
6. 2〜3 が「なし」なら PHP・Node の対応は要らない。4 に行があれば `sudo apt-get upgrade -y`（myacady は止まらない。cloudflared が上がれば数秒切れる）。5 が enabled・active でなければ `sudo apt-get install -y unattended-upgrades && sudo dpkg-reconfigure -plow unattended-upgrades`。
7. Mac：`node -v`（app/tools の検査に使うなら 24.22.1 か 22.23.4 へ `brew upgrade node`）、`brew list | grep -E -i 'php|node'`（php があれば `brew upgrade php`）。

## 却下した案
- Cloudflare の WAF（管理ルール）で PHP の攻撃の形を止める：PHP が無いので要らない。入れても害は無いが、いま足す理由にならない。
- Claude が本番へ入って確かめる：権限の線で禁止（本番は読むだけ）。本人の命令文にした。

## 影響
- 検査・画面の流れ・巡回・ラベルの 4 本の workflow が、次の実行から Node 24 で動く。runner は GitHub の ubuntu-latest（2.327.1 以上）。
