# 用語

| 言葉 | 意味 |
| --- | --- |
| 校舎 | テナント。本物は `waseaca-london`（コード w）、架空のデモは `london` |
| 席 | まだ渡していない口座（role=seat）。名簿にも宿題にも出ない。渡すと在籍の生徒になる |
| 口座 | ID と合言葉の組。生徒 `s-000`・講師 `t-001`・開発者 `d-001`（10-01 から）。以前の形は `w`＋生徒番号（席の表に残る） |
| 合言葉 | パスワード。サーバは合言葉そのものを受け取らない（SCRAM の検証子だけ） |
| 合言葉の表 | iCloud の `合言葉の表.nosync/`（xlsx）。読まない・送らない・写さない |
| 束 | 1 回の授業の紙の宿題のまとまり（評価は束に 1 つ）。または校舎の口座とコースの一式（bundle.json） |
| 提出箱 | 写真を出す箱。種類（漢字テスト・計算テスト・英語テスト・作文・過去問の添削）と相手（全員／選んだ生徒だけ）がある。過去問は 1 本＝1 箱 |
| 上位・個別 | 追加の宿題（extra）と生徒ごとの決まり（personal）。普段の回の束に入る |
| コース | クラス × 教科。講師がコースごとに「使う」を選ぶ（既定は使わない） |
| 導入の段階 | 0〜4。毎日テストは段階 4 でだけ出る |
| 混在 | 紙のクラスとアプリのクラスが半年以上同居すること。混在しても便利であることが必須 |
| 5 週周期 | 単元確認テスト（組み分けテスト）が 35 日ごと。分量と反復の前提 |
| ためしのデモ | 本物の校舎の今ある口座に作る見本の記録（`demo_trial.py`）。clean で席に戻る |
| ためしに見る | 入口の一覧（`deploy/ためしに見る.json`）。ID だけで入る。試し運用のあいだだけ |
| ためし運用の印 | `TRIAL=1`。本番切替（go-live）で外れる |
| 本番切替 | `deploy/本番切替.sh`。生徒を退避し、ためし運用の印を外す。まだ流していない |
| 反映 | 本番サーバへコードを送ること。本人が `sh deploy/更新.sh` |
| 巡回 | 本番を読むだけで意味の検査をし、差を記録に書くこと（patrol.sh → routine へ） |
| 意味の検査 | `expect.py`。動くかでなく、数字が目的に照らして正しいか。前回との差は ledger |
| 不変条件 | 不具合を直したときに足す検査（expect.py か test_*.py） |
| 写し | スクリーンショット。4 つの役×3 幅、WebKit で撮る |
| ずれ | 横はみ出し・窓の外・親からのはみ出し・重なり・小さい押し場所（adm_flow15 が数える） |
| 番人 | `.claude/hooks/guard.py`。絶対ダメを機械的に止める hook |
| 外部脳 | `knowledge/`。人も Claude の各チームも ChatGPT も同じものを読む。原本は GitHub。Docs は写し（Drive の写しは 2026-10-20 でやめた） |
| 決定録 | `knowledge/70-決定録/`。決めたこと・理由・却下した案・影響 |
| 種 | `knowledge/90-種.md`。改良の種（issue に写す前の置き場） |
| 控え | 読むだけの写し（iCloud の tube-schools、`紙の宿題/控え/`） |
| 前身 | Tube English（`../myenglish/`。触らない）と tube_next・firebase（Git に入れない） |
