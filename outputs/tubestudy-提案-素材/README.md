## 52秒版（2026-09-13 夜）

- `../tubestudy-紹介動画.mp4` … **52秒・音つき**（1920×1080・30fps）。`../tubestudy-紹介動画-無音.mp4` は同じ映像の無音版。30秒版は `-30秒版` の名前で残してある。
- 作り：`紹介動画/promo2.html`（タイムライン。`seek(t)` で1コマ）→ `render2.py`（Chrome で 1,560 コマ）→ `encode`（MP4）→ `music2.py`（BGM＋効果音。numpy だけ）→ `afconvert` で m4a → `mux`。写しは `紹介動画/shots2/`（最新のデモ画面、架空データ。`jobs.json` が撮り方）。
- 構成（各 5 秒、96 BPM の 2 小節）：印 → 紙のまま写真で出す → 今日やること → なぞるだけで評価 → 【これもできます】iPad でそのまま赤 → 【そしてこんなことも】一人ひとりの宿題 → 【これもできちゃうんです】保護者とやりとり → 【でも、これも大事に】サーバに氏名はありません → 紙も赤ペンも先生の目もそのまま → 先生の時間を授業へ → 印。
- 音：場面ごとに層が増え、保護者で頂点、プライバシーで一度静かに、締めでもう一度。43.4 に弱いジャーン → 46.6 で無音 → 47.0 の印の「ぽこん」（映像の弾みと一致を計測ずみ）。
