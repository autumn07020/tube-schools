# 紹介動画（67秒・第4版 2026-09-14）の素材

- `promo4.html` …… 画面の時間割（1920×1080、`seek(秒)` でその瞬間を描く）。写しは `shots2/`。
- `coords4.js` …… 写しの中のボタン位置（「出す」・グラフの黄色い棒・つまずいている子の行・プリセット）。撮り直したら測り直す。
- `music4.py` …… 音（numpy で合成 → `bgm4.wav` → `afconvert -f m4af -d aac -b 192000` で m4a）。
- `render4.py` …… Chrome を裏で動かして 30fps・2010 コマを PNG に描く。引数に秒を並べると、そのコマだけ（確認用）。
- 仕上げ …… `bin/encode frames4 out.mp4 30 1920 1080` → `bin/mux out.mp4 bgm4.m4a 紹介動画.mp4`。

## 決まり（遠くのスクリーンで分かるために）
文字は大きいものだけ（見出し 96〜120px、添え書き無し）。各章は「文字が先に出る → 画面が出る → 動きは1つ → 最後に止まる」。
文字の切り替えは章あたり最大2回。主人公は「生徒」「先生」のラベルで示す。
