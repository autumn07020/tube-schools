## 1. TUBE study とは

**早稲田アカデミー ロンドン校の、講師と生徒のための宿題システム。** 宿題を出す・確かめる・写真で出す・採点して返す、を1か所で行う。
それに、毎日テスト（間隔をあけて戻ってくる小テスト）と、5週ごとの組み分けテストの対策が付く。URL は https://tube-study.uk 。

| | |
|---|---|
| 使う人 | 生徒 小4〜中3（9〜15歳）／講師（コンピュータが苦手な人が前提）／保護者（生徒の端末の中の「保護者の方へ」。別の口座は無い）／管理者（講師のうち1〜2人） |
| いつ開くか | 生徒：家で宿題をするとき（「今日やること」）。講師：授業の前後（「宿題チェック」と「今日やること」）。管理者：席・講師・担当を足し引きするとき |
| 機械 | 生徒は iPhone が主（Safari。ホーム画面に置ける）、家のパソコン・iPad でも。講師はパソコンと iPad（ペンで赤を入れる）、授業の合間は iPhone |
| 匿名 | **氏名・連絡先をシステムのどこにも持たない。** 生徒は ID（`s-042`。無作為の3桁）だけ。画面の呼び名は「小4α s-042」。講師は `t-001`、管理者は `d-001` |
| 登録 | 保護者が、塾の配る登録コード（QR）から自分で口座を作る。学年・クラス・受講科目は自己申告で、設定からいつでも直せる |
| 5週の周期 | 4回の新しい単元＋5回目の総復習。5週ごとに組み分けテスト（α⇄β・T⇄R が入れ替わる）。月や年ではなく、この周期で全体が回る |
| 部分導入 | 講師がコース（クラス×教科）ごとに「導入の段階」を決める：0 紙のまま／1 宿題を出す／2 写真で提出／3 添削まで／4 毎日テストまで。紙のクラスと半年以上まざる |
| 宿題の形 | 「この教材のこのページ」（文字の範囲）。紙に解いて写真で出すものと、アプリの中で解くものがある |
| 評価 | 講師が 5段階：5 よくできた／4 できた／3 もう少し／2 がんばろう／1 やり直し（0 出ていない）。ひとことと、赤を入れた答案を返せる |

## 2. 思い違いしやすい所 ―― 実物はこう

10/3 の「Tube study デザインシステム」（v0）と、A/B テストの試作は、**チャット版の Claude が、実物を見られないまま作ったもの**。v0 は無視してよい。A/B の結果（見た目の好み）は `04` にまとめてある。
実物を見ないと、次を思い違いしやすい。

| 思い違い | 実物 |
|---|---|
| 主な利用者は生徒で、講師の画面は後付け | **講師の画面が半分。** 宿題チェック・成績・導入と進度・授業の紙・赤を入れる紙・管理ページがある（第4〜6巻） |
| Tube study は宿題を受け取って見せるだけで、作る画面は別のアプリ | **Tube study そのものが宿題システム。** 出す・確かめる・採点する・返す、を全部ここで行う |
| 講師が、1件ずつフォームで宿題を出す | 宿題は**授業計画から自動で出る**。講師が手で触るのは、授業の紙（ずらす・止める・提出箱）と、宿題を足す紙 |
| 画面は一覧（リスト）が中心 | **札（カード）の格子。** iOS のホーム画面のウィジェットを手本にしてきた |
| 「Tube」はロンドン地下鉄で、学習を路線図にたとえる | たとえは**使っていない**（本人：「路線図という言い方は AI 臭い。不要」）。ログインのあとの幕の一言「All aboard!」と、印（輪と横棒）に名残があるだけ |
| 生徒を、色やニックネームで見分ける | **ID（`s-042`）とクラス名**（「小4α s-042」）。色もニックネームも持っていない |
| ホーム画面アプリとして、裏で動く仕組み（Service Worker）がある | **無い。** 記録は端末とサーバの両方に置き、送れなかった分は回線が戻ったら送る |
| 暗い配色がある／無い | CSS に値はあるが、**切り替える場所が無い**（常に明るい）。暗い側は仕上がっていない（S暗-＊） |

### よく聞かれること
1. **一文で言うと** ―― 1章の太字。
2. **今ある画面ぜんぶ** ―― 第0巻（早見）と第1〜6巻。281 画面・502 枚。表は「02-画面台帳.md」。
3. **どこが弱いか** ―― 本人：「デザインが未だ洗練されていない」。試作への判定は「構成は良い。色合いとフォントです」。数えた結果は 6章、作っている側の見立ては 11章。
4. **何で生徒を見分けるか** ―― ID（`s-042`）。画面では「小4α s-042」。講師は、生徒がノートの上に書いた ID で見分ける。
5. **技術** ―― 素の JavaScript（フレームワークもビルドも無い）。画面は JS の文字列で HTML を組む。CSS は3本（9章）。CSS 変数あり。
6. **目標** ―― `04` の 1章（Apple のフィットネス・ヘルスケア、iPhone のホーム画面、リキッドグラスと分かりやすさ）。
7. **ダークとオフライン** ―― どちらも要件として決まっていない。既定は明るい。ダークは「こだわりなし」。

## 3. 北極星 ―― 判断の軸（開発の決まりの原本から）

**大目標**
- 一講師として、ロンドン校の役に立つ。講師の時間を授業へ。生徒の宿題と成績の「あいだ」を仕組みで支える。
- 買い手は組織ではなく、現場の講師と生徒。売り文句を作らない。
- スロースタート・部分導入が前提。使う講師だけ、使う教科だけ、使う深さだけ。使わない講師には何も要求しない。
- お金をいただいて運用する。張りぼては不可。壊れない・嘘をつかない・戻せる、が価値より先。

**誰のために**
- 講師：コンピュータが苦手な人が前提。覚えることを作らない。数字は入力させず、押すだけ。
- 生徒：小4〜中3。小5以下はかな多め、小6以上は講師と同じ漢字。
- 遠くのスクリーンで見る50代の人にも分かる大きさと言葉。

**圧倒的なわかりやすさ**
- 1画面に「次にやる1つ」を先に出す。大量のタスクを並べない。
- 見出しは日本語だけ。中身をそのまま言う短い名前。タブと同じ中身ならタブと同じ名前。
- 抽象的な言い回しを使わない。動作だけを言う（写真を選ぶ・数字を押す・赤を入れる・返す・足す）。
- 数字には必ず根拠を添える。分からないものを 0 と出さない。紙の子を不真面目に見せない。
- 小さな添え書きに頼らない。読む時間が無い前提で、大きな文字だけで伝わるか。

**美しさ**（いまの実物は、この考えで作ってある。これからの見た目の向きは `04`）
- 線を引かない。面と地の明度差、影（髪の毛ほどの縁＋近い影＋遠い影）、上辺の光で面を立たせる（Apple のウィジェット）。
- 色は早稲アカの青と黄。教科の色は薄く。達成の黄は濃い所を狭く。
- 角は大きく。絵文字・記号アイコンを使わない。階層は大小と余白で作る。
- 押せるものは必ず押せる。押した手ごたえ（沈む）。44px の当たり判定。
- 同じ概念は同じ見た目。新しい部品を作る前に、ある部品で書けないか。

**単純な論理**
- 概念を増やさない。推測より明示。出したあとの記録を書き換えない。誰にも追加入力をさせない。

## 4. いま守っている決まり

組み立て（4.1）・言葉（4.2）・数字と図（4.3）・押せるもの（4.8）は、見た目が変わっても土台になる。色・面・角・動き（4.4〜4.6）は、いまの実物の記録で、これからの向きは `04`。

### 4.1 画面の組み立て
- **白い箱で節ぜんぶを囲まない。** 札は1枚ずつ。節の見出しは、左に青→黄の縦の柱（幅5px）＋大きな日本語。説明文は付けない。
- **札は4種だけ**：濃い面（その画面でいちばん見てほしい1つ。黄→青のぼかし。**1画面に1つ**）／青の淡い面＝押して先へ／黄の淡い面＝手を入れる・祝う／白＝それ以外。
- **ページを移動させない。** 詳細・採点・予定は「紙」（重なって出る面）で出す。開いてもページは1pxも動かない。閉じる道は ×と、後ろの暗がりの2つ。紙の中から紙へ移れる。
- **押したものは動かない。** 描き直しても巻き位置を保つ。保存のあとに「よみこんでいます」に戻さない。
- **並びは1つに固定する**（名前の順）。理解度や遅れで並べ替えない。目立たせたいものは印と色で示す。
- 今いるタブをもう一度押したら、そのタブのいちばん上へ。
- 生徒のホームは「今日やること」と「自分の記録」の2つだけ。宿題のタブの上の段は、ホームとまったく同じ札。
- 講師の「今日やること」に置く図は、輪の1つだけ（宿題チェック あと○件）。

### 4.2 言葉
| 使う | 使わない | なぜ |
|---|---|---|
| 採点する・チェックする | 見てあげる | 何をするかが動詞で分かる |
| 9/10人 | 90% | 分母が10人なら、そう言えばいい |
| まだ・未評価 | 遅れ・評価まだ | 続ける気を削がない／講師の言い方は「未評価」 |
| 算数（小学）・数学（中学） | 一律に「数学」 | 学年で呼び方が違う |
| 動作のことば（赤を入れる・返す） | 「赤ペン」「先生の目」「あたたかみ」 | 本人が禁止。抽象的な言い回しを使わない |

- **見出しは日本語だけ。英語を添えない。**（前は「Today きょうの宿題」の形だった。やめた）
- **生徒の画面には％を出さない。** 成績の伸びは図と3段のことば（いい調子／いい感じ／がんばろう）。数字は保護者と講師だけ。
- **責めない。** 期限を過ぎても「先に取り組もう」。未提出や遅れの数を、生徒の「先生から」には出さない。0 の札は出さない。
- 期限の形は1つ：「あと4日」と「9/15(火)」を1枚の札に。色は3段（今日まで・過ぎた＝黄／今週＝青／来週＝灰）。
- 確かめは画面の中で取る（ブラウザの confirm は使わない）。壊す操作は2度押し。
- 小5以下の生徒の画面は、かな多め・分かち書き（`jp('きょう やること','今日やること')`）。**同じ画面で文字数が大きく変わる**（S01 を lj2r01 と le4b01 で比べる）。

### 4.3 数字と図
- 数字は札ごとに大きな1つ（細く大きく）。図の点や棒に数字を振らない。横軸に第何回を書かない。
- 推移は折れ線（右端が最新。最新の点を濃く）。人数は1人1点、割合は小さな輪、進度は単元の列、教材は冊子の形。四角には凡例を添える。横棒グラフは使わない。
- 満ちた目盛りは青→黄に抜ける。

### 4.4 色
- **色は意味のある所だけ。** 青＝進んでいる・選ばれている・押して先へ。黄＝今日・いま手を入れる所・達成。それ以外は無彩色。
- **黄は1本しか持たない**（面・地・字・線の4つの濃さ）。`#F9B900` は白地の字にすると 1.8:1 で読めないので、字は `#8A5A00`。
- 教科の色は薄いグラデーション（左上から差して消える）：国語＝赤とピンクの間、算数・数学＝青、理科＝緑、社会＝黄、英語＝緑と青の間。教科名を必ず書く。
- 地は iOS の壁紙のようにごく淡いグラデーション（左上に黄、右下に青）。札の光の向きと同じ。

### 4.5 面・影・角
- 線は表の罫だけ。区切りは面と余白。
- 札は白＋やわらかい影＋上辺の光。役割のある札には淡い色。
- 角：札 22px／講師の札 20px／時間割のコマ 18px／行 16px／ボタン 14px／入力欄 12px／紙 26px／カプセル 999px。四角い印は一辺の 22.37%（iOS のアイコンと同じ比）。

### 4.6 動き
- **transform と opacity だけ。** `prefers-reduced-motion` では全部止める。
- **画面の移り変わりはフェードだけ**（本人：上下・左右に動くのは気持ち悪い）。前の画面が 0.5秒で薄れ、次が 0.7秒で浮かぶ。データが届いただけの描き直しには付けない。
- 紙は拡大しながら出て（0.55秒）、縮みながら消える（0.35秒）。入りの動きで位置を変えない。
- 押せるものは全部、同じ反応：押した瞬間に沈んで戻る（0.45秒）。マウスでは乗せると少し大きく（0.3秒）。色が暗くなる反応は無い。**宿題チェックの中だけ付けない**（1〜5 を連打する所）。
- 短すぎる動きにしない（本人：短いとせっかちに見える）。
- ログインのあとは幕：印が弾んで出て、銘と呼び名が続き、白い輪がほどけて右へ消え、約3秒でホームが明ける。一言は「All aboard!」（E07・E08）。
- はじめての端末は「ようこそ」：印が弾み、輪が広がり、文字が1つずつ出る（E01・E02）。登録の完了も同じ動き（E22・E23）。

### 4.7 並べ方
- **画面の幅ではなく、入れ物の幅で決める**（container query）。左のタブがあるので、画面の幅と中身の幅は一致しない。
- 列の数は「割り切れる数」だけ。札の合計を6つぶんにそろえ、1・2・3列。iPhone でも札は2列（1列にすると宿題まで指を3回すべらせる）。
- 広い画面は列を増やさず、本体を 1320px で止めて中央に寄せる。**講師の画面は止めない**（40人ぶんの帯は横に広いほど読める）。
- 紙は 641px 以上で中央に浮かび（幅 680px）、640px 以下では下から全幅。
- タブ：iPhone は下に文字だけの帯（生徒4つ・講師3つ）。広い画面は左に縦のタブ。右上に「･･･」のメニュー。

### 4.8 押せるもの
- 押せそうに見えるものは必ず押せる。飾りのボタンを作らない（機械で検査している）。
- 当たり判定は 44px。小さく見える文字だけのボタン（`.lnk`）も、見えない所で 44px にする。

### 動きの値

- フェード：消える 0.5秒・浮かぶ 0.7秒。紙：出る 0.55秒・消える 0.35秒。暗がり：0.5秒／0.35秒。押した反応 0.45秒。乗せる 0.3秒。お知らせ（toast）0.45秒。
- 幕：印 0.95秒 → 輪がほどける 0.7秒 → 明ける 0.9秒。ようこそ：印 1.05秒・輪 0.9秒・文字 0.55秒ずつ・点 1.25秒。

## 9. 技術の前提（デザインを実装できる形にするために）

- **素の HTML・CSS・JavaScript。** フレームワークもビルドも無い。画面は JS が文字列で HTML を組んで差し替える。だから、**静的な HTML＋CSS の見本がそのまま実装の元になる**（React の部品でなくてよい）。
- **外から何も読まない**（CSP `default-src 'self'`）。Web フォント・アイコンフォント・CDN は使えない。画像は自分のファイルか `data:`。アイコンを使うなら**インラインの SVG**。インラインの `onclick` は動かない。
- 色は CSS 変数。並べ方は container query。動きは transform と opacity だけ。
- **Safari が主**（iPhone・iPad・Mac）。Chrome・Edge でも同じに。動く下限は iOS／Safari 16.2。`backdrop-filter` は `-webkit-` も書く。
- ホーム画面に置ける（`apple-mobile-web-app-capable`）。`viewport-fit=cover`。上下の安全な余白（`env(safe-area-inset-*)`）を足す。置いたときは戻るボタンが無い。
- 入力欄の字は 16px 以上（iOS が勝手に拡大しないように）。押した手ごたえは自前で描く。
- 写真の上にペンで書く紙（T06）は canvas。図は自前の関数（SVG）。
- 明るい配色が主。暗い配色を作るなら、全部の色に暗い値を（いまは切り替える場所が無い）。
- 氏名・顔写真・アバターは**どこにも無い**。入れる場所を作らない。
- 大きさ：iPhone 390×844（375 でも崩れない）／iPad 820×1180・1180×820／パソコン 1440×900（窓を縮めても崩れない）。

## 11. 弱い所の見立て（作っている側から。Claude Design への問い）

1. **文字の階層が多すぎて、小さい。** 59 種類。13px 以下が7割。iOS の文字の段（大見出し・見出し・本文・注）のように、5〜8段に畳めるか。
2. **角・影・淡い色が、名前なしで増えた。** 角 14種・影 17種・面の色 29種。新しい指針では、名前の付いた段だけにしたい。
3. **札の言語が画面ごとに違う。** ホームの札（S01）、出題の画面（S18-＊。灰色の行だけ）、管理ページ（A10〜）、初回登録（E13〜）、紙の宿題の道具（N-＊）が、別々に育った。1つの体系にしたい。
4. **生徒のホームが長い。** iPhone で 2,219px（画面 2.6 枚ぶん）。お知らせがあると「いまやるならこれ」が2枚目になる（S01）。
5. **44px 未満の押せる部品が 110か所。** 文字だけのボタンと、選ぶカプセル。
6. **下のタブが文字だけ（11px）。** 絵文字・記号アイコンを使わない決まりだったため。新しい向き（`04`）では、線のアイコン＋語の、浮いたタブバー。
7. **広い画面で、中身の少ない画面が小さな札として浮く。** 設定・報告・登録コード（S13・S15・E10 のパソコン幅。E10 は字間も開いて見える）。
8. **暗い配色が未完成。** 淡い面（`--tint-*`）が明るい色のまま。切り替えも無い。作るか、やめるかを決めたい。
9. **動きの仕様が1か所に無い。** 26 種類の動きが CSS に散っている。iOS に寄せるなら、ばねの動きと、紙を引いて閉じる動きをどうするか（本人の「フェードだけ」「短すぎない」と合わせて）。
10. **講師の「成績」「導入と進度」は情報が多い。** 表と小さな字が中心（T09・T16・T17）。コンピュータが苦手な講師が、押すだけで済む形になっているか。
11. **空の状態が素っ気ない。** 登録直後の生徒（E24〜E27）と、担当の少ない講師（T501・T502 の講師3・4）。
12. **ラベルの字が薄い。** `--text3`（`#A1A1A6`）は白の上で 2.6:1。11px のラベルと下のタブに使っている。
13. **ガラスのような半透明の面は、上の帯と下のタブにしか無い。** 新しい向きでは、札もタブも全部ガラス。Web（Safari）ではぼかしが重くなりやすいので、作り方に条件がある（`04` の 8章）。
