# Claude Design に渡すプロンプト（そのまま貼る）

- **一気に決めない。** 段を踏んで、たくさん試して、絞る（`04` の 6章）。プロンプトは段ごとに1本。上から順に。段 1〜3 は行き来してよい。
- どのプロンプトも、それだけで通じるように書いてある（前のセッションを覚えていない前提）。**`01` と `04` は毎回添付する。**
- 各段の終わりに、Claude Design に「この段で決まったこと」を `04` と同じ形（強／寄り）で書かせる。それを `04` の付録の下に貼り足してから、次の段へ（次のセッションが、前の答えを読めるように）。
- 選ぶもの・添付するものは各プロンプトの頭。理由は `00-はじめに読む.md`。

## 段1 広く試す（生徒ホーム）

**選ぶもの**　Design system：`None`　／　テンプレート：`Mobile app design`　／　codebase：なし　／　モデル：Fable 5.1 か Opus 5.5
**添付**　`01`・`04`・`第2巻 生徒（iPhone）.pdf`

```
TUBE study の生徒ホーム（S01）を、新しい見た目で 6〜8 通り試作します。実装は Claude Code が別に行う。

【添付】01＝いまの実物の事実。04＝これからの見た目の向きと進め方（見た目は 04、機能と中身は 01）。第2巻＝いまの画面の写し（S01 は先頭）。

【土台（全部の試作に共通。04 の 2章）】
- ライト。札もタブも全部ガラス。**背景は画面に固定し、札だけがその上を流れる。**
- 書体は -apple-system（SF＋ヒラギノ角ゴ）。数字は ui-rounded。大きな数字が主役。進捗はリング。
- 操作の色は青1色（#0A6FC7 → #004E93）。色の多様さは「教科の印」と「淡い背景」で出す。青一色の画面にしない。

- 出発点の値は 04 の 2.3（ガラス 白20%・ぼかし8px・彩度1.9／光る縁／背景のにじみ 0.35・地 #F3F1EC／教科の色）。

【振るもの】試作ごとに、次のうち 1〜2 個だけを変える。何を変えたかを、アートボードの題に書く（例：「S01-c 背景：にじみ2色・左上」）。
背景のにじみ（色の数・位置・濃さ）／ガラスの透け方（白 15〜45%）／文字の段と太さ／余白と札の高さ／札の並べ方（次にやる札の大きさ、2枚の組み方、教科の見せ方）／教科の印の形（チップ・アイコン・点）

【守ること】
- 390×844。1枚は全長（下まで）。文言と数は、第2巻の S01（中2R の生徒）のまま。架空の文を作らない。
- 04 の 3章（変えないもの）：氏名や顔写真を入れない／生徒の画面に％を出さない／見出しは日本語だけ／押せそうなものは押せる（44px）。

- 実物のホームにあって試作A に無いもの（先生からのお知らせ・成績の伸び・今週の目標 など）は、段0 で決めた置き場に。

【終わりに】並べて見せ、1つずつ「何を試したか」を1行で。Ken が 2〜3 に絞ります。絞ったら「この段で決まったこと」を 04 と同じ形（強／寄り）で書く。
```

**添付**　`01`（4.6 と 5章の「動きの値」）・`04`・`第1巻`

```
TUBE study の動きを、新しい見た目に合わせて作ります。画面の見本は、次のキャンバスにあります（リンク：＿＿＿）。

向き（04）：画面の移り変わりはフェード。部品はばね系（押した反応・紙・リング）。達成は静かに、1回だけ。短すぎない。宿題チェックの中では押した反応を付けない。動きを減らす設定では全部止める。
いまの動きは 01 の 4.6 と 5章。実装は CSS の transform と opacity だけ（JS で計算しない）。

```

ここまでの成果を、実装する Claude Code に渡す束にまとめます。Claude Code は、デザインシステムとキャンバスのリンクから中身を読めます。
