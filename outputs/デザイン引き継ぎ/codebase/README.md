# codebase ―― 画面のコードの写し（読むだけの参考。2026-10-04）

TUBE study の画面を作っているファイルだけを、本体（`tube-schools/app/`）から写したもの。**ここを直しても、本物は変わらない。** 実装は Claude Code が本体に対して行う。
Claude Design では、いまの HTML の組み方・部品の名前（クラス）・文言を正確に引くための参考に使う。

| ファイル | 中身 |
|---|---|
| `css/app.css` | 本体の見た目（4,116行）。先頭の `:root` に色・影・角の変数。直しを上に重ねてきた作りなので、同じ部品の指定が何か所にもある（**あとに書いてあるものが効く**） |
| `css/admin.css` | 管理ページ（/admin）。本体とは別に書いてある |
| `css/join.css` | ようこそ・初回登録・組分けの札 |
| `js/ui-core.js` | 画面の切り替え・上の帯とタブ・ログイン・幕・メニュー・報告。`jp('かな','漢字')` が学年で文言を出し分ける |
| `js/ui-student.js` | 生徒：ホーム・宿題・毎日テスト・先生から・保護者の方へ・設定・出題 |
| `js/ui-teacher.js` | 講師：宿題（今日やること・時間割）・導入と進度・導入の段階・教材 |
| `js/ui-desk.js` | 講師：宿題チェック（写真／対面）・赤を入れる紙・成績・生徒の紙 |
| `js/ui-join.js` | ようこそ・初回登録・クラスを変える |
| `js/admin.js` | 管理ページ |
| `js/viz.js`・`js/cheer.js` | 図（折れ線・輪・帯）を SVG で作る関数／積み上げの数え方 |
| `index.html`・`admin.html` | 入れ物（中身は JS が組む） |
| `icon.svg` | 印（青い角丸の四角に、白い輪と黄の横棒） |
| `terms.js` | 利用規約の文（名義は仮） |

- フレームワークもビルドも無い。画面は、JS が文字列で HTML を組んで `#main` に入れる。HTML の形を知りたいときは、JS の中の `'<div class="…">'` を読む。
- 外から何も読まない（CSP）。Web フォント・アイコンフォント・CDN は使えない。
- 教材のデータ・サーバのコード・検査の道具は、ここに入れていない。
