# プレゼン台本 ―― 宿題チェック → 添削（印刷／iPadで直接）→ 返す → 生徒に届く

明日の実演用。**講師版と生徒版を同じブラウザで行き来してよい**（ログアウト → 入口の「ためしに見る」→ 別の人。前の人の控えは残らない）。
iPad があれば講師版を iPad で開き、生徒版は iPhone か PC で開くと「行き来」が見た目にも分かる。

URL：https://tube-study.uk（デモの合言葉は入口の「ためしに見る」で入る）

## 0. 事前確認（前日）
- `sh deploy/更新.sh` で今日の分を本番へ。入口の「小4β の生徒」の添え書きが **「漢字テスト・記述問題を写真で。添削つき」** になっていれば反映ずみ。
- 講師で入り、今日やることに **「小4β 国語　記述問題 説明文の最終問（100字）」の札（3人 未評価）** があること。
- 本番はデモの合言葉のまま（`demo: true`）。実名は入っていない。

## 1. 生徒版（小4β の生徒）―― 出す
1. 入口 →「ためしに見る」→ **小4β の生徒**。
2. ホームの「いまやるなら これ」に **記述問題** が出る（期限は昨日＝「先に取り組もう」）。**出す** を押し、原稿用紙の写真（iPad/iPhone のカメラでその場で撮る、か用意した写真）を選ぶ →「まとめて出す」。
3. 言うこと：「写真を撮って出すだけ。ノートの写真か PDF、6枚まで。出したかどうかは先生の画面にすぐ出る」。

## 2. 講師版 ―― 宿題チェック
1. メニュー → ログアウト → 入口 →「講師として見る」。
2. 今日やること：**小4β 国語 記述問題** の札 →「チェックする →」。
3. 左のマスで出した子を押す（いま出した 小4β-01 も入っている）。右に原稿用紙が大きく出る。
4. 評価は **1〜5 のキー**（or ボタン）。ひとことを1行。言うこと：「写真を見ながら数字とひとことだけ。1人 10秒」。

## 3. 添削 ―― 2つの道（どちらも1タッチ）
**A. 印刷して赤を入れる（従来）**
- 添削の札 ①「印刷する」→ 印刷の窓（A4 に1ページ1枚）。紙に赤を入れる → ②「撮った写真を選ぶ」で撮り直しを選ぶ → その瞬間に返る。

**B. iPad で直接（新）**
- 添削の札 ②「**この画面で書く ✎**」→ 出された写真の上にそのまま書く（Apple Pencil・指・マウス）。赤／青、太さ、ひとつ戻す、ページ送り。
- ひとことを書いて「**返す**」→ 全ページが赤つきで返る。「返した添削 n枚」が右に出る（押すと返した紙が見られる）。
- 言うこと：「印刷せずにその場で返せる。返した紙は生徒の『先生から』にすぐ出る」。

## 4. 生徒版 ―― 届く
1. ログアウト → 入口 → **小4β の生徒**。
2. 「先生から」タブ → 国語 → 記述問題の札に **評価・ひとこと・「添削された答案を見る（n枚）」**。押すと赤の入った原稿用紙が開く（ページ送り可）。
3. 言うこと：「評価・ことば・赤の入った答案が1つの札に。保護者も『保護者の方へ』から同じものを％つきで見られる」。

## 5. もう一度やりたいとき
- 同じ子に何度でも返せる（返した紙は差し替わる）。他に **未評価が3人**、**返した見本が1人** いる。
- 本番のデモは `sh deploy/デモを作り直す.sh`（サーバ側）で初期状態に戻せる。更新（`更新.sh`）でも作り直る。

## 6. うまくいかないとき
- 写真が出ない → 通信。ページを開き直す。
- 「この画面で書く」が薄い（押せない）→ その子はまだ写真を出していない（未提出の子には出ない）。
- iPad で指が反応しない → ペンで書いた直後 1.5秒は指を無視する（手のひら除け）。少し待つか、ペンで。
