# プレゼン構成 ―― ロンドン校での試験導入をお願いする（10分以内・動画と実演込み）

目的はひとつ。**一講師である私が作ったものを、ロンドン校で試験的に使わせていただくこと。**
お金や契約の話はしない。姿勢は最後まで謙虚に。「役に立ちたい」から始めて「お願い」で終わる。

スライドは `tubestudy-提案.pptx`（旧版の様式・10枚・動画埋め込み）。読み原稿は各スライドの発表者ノート。
実演の手順は `実演の手順-プレゼン用.md`。動作だけを言い、抽象的な言い回しは使わない。

## 各スライドで話すこと（発表者ノートと同じ）

**1 表紙** こういう機会をいただけて、本当にありがとうございます。ロンドンに着いたばかりで、日々教わることばかりです。今日は、役に立ちたくて作ったものを見ていただき、ロンドン校で試しに使わせていただけないか、というお願いです。

**2 「授業準備」以外の大切な仕事** 宿題を集めて、見て、返す。得意と苦手を生徒ごとに見る。提出と伸びを家庭に伝える。どれも一人ひとりに向き合う仕事で、生徒が増えるほど、この時間も増えます。質を保ったまま、効率的にしていきたい。それが出発点です。

**3 3つの目的** 講師の時間を授業へ。一人ひとりに本当に向き合う仕組み。そして、これまで人の力で達成してきた生徒数を、仕組みで支える。誰もが使える、宿題と成績管理の仕組みをつくりたい。

**4 tubestudy** 生徒、講師、保護者が毎日使える、宿題と成績管理のサービスです。講師はパソコンか iPad、生徒と保護者はスマホ。紙のクラスと混ざったまま使えます。言葉より、1分ほどの動画で。

**5 動画** 再生。終わったら 2〜3 秒黙って、反応を見る。

**6 できること** 講師は、見るべき宿題が上に並び、写真を見て1〜5を押す。iPad で赤を入れて返す。理解度から宿題を足す。生徒は、今日やる宿題がひと目で分かり、ノートを撮って出すだけ。評価と赤の入った答案が届き、毎日テストで苦手をつぶす。保護者は、成績と先生のことばを見られ、相談を送れ、返事も同じ画面に届く。ここからは、実際の画面でお見せします。

**実演（3分）** 別紙のとおり5つ。生徒が写真で出す → 先生が数字を押し、気になる子には赤を入れて返す → 生徒に評価と続けた記録が届く → 先生の側に理解度が残り、つまずいている子に宿題を足す → 保護者のページ。

**7 与える価値** 講師は、手作業が減って授業の準備に時間を回せ、チェック忘れが無くなり、担当が変わっても記録が残る。生徒は、出した・見てもらったが毎回残り、続けた記録が続ける力になり、自分の苦手から問題が出る。保護者は、見てもらっていることが伝わり、成績の伸びが見え、相談の窓口がある。成績が上がり、講師の質が上がり、保護者の評価が上がる。その循環を仕組みで支えたい。

**8 あっと驚く簡単さ** 評価は押すだけ。写真は撮って送るだけ。導入はコースごとに選べ、紙のクラスと併走できる。

**9 原理的に安全です** 保護者や生徒の個人情報は入れません。名簿は塾の手元の紙だけ。早稲田アカデミーの教材データも入れません。入れるのはカリキュラム、単元の並びと生徒番号ごとの記録だけ。本部のシステムに全くつながなくても、個別指導塾のようなパーソナライズ宿題と成績管理が成立します。

**10 締め** 先生の時間を、授業へ。もっと。まず、私の担当クラスから、試験的に使わせてください。費用も契約もありません。紙のクラスと混ざったままで動き、いつでも紙に戻せます。3か月後に数字でご報告します。ありがとうございました。

## 想定問答（聞かれたら短く）

| 質問 | 答え |
|---|---|
| 個人情報は大丈夫か | サーバに氏名・住所・電話はありません。番号と記録だけ。名簿は塾の手元の紙。パスワードも合言葉も元に戻せない形で置き、判定はすべてサーバ側。自分で攻撃して塞いだ記録もあります（SECURITY.md） |
| 本部のシステムや教材との関係は | 本部のサーバには一切つなぎません。教材データも置きません（教材名とページ、正誤だけで回る設計）。本部のオンライン化の流れと矛盾せず、現場の手作業を減らす補助です |
| 費用は | かかりません。サーバは私が個人で用意しています（英国ロンドン）。試験導入の間はそのままで |
| あなたが居なくなったら | 仕組みと手順は文書にしてあります（引き継ぎ書・仕様書・更新手順）。止めるときは紙に戻すだけで、記録は消せます |
| 先生の負担が増えないか | 先生の操作は「写真を見て数字を押す」「赤を入れて返す」だけ。使うコースを先生が選び、紙のクラスと混在できます |
| 保護者への説明は | 校舎の名前でご案内を出したい。文面は用意します。保護者は生徒の端末の中の「保護者の方へ」から見るだけで、別の登録は不要です |
| 成果はどう測るか | 3か月で、宿題の提出率・チェックが行き届いた割合・返却までの日数・保護者の反応を数字で報告します |

## 話し方の決まり
- 動作だけを言う（写真を選ぶ・数字を押す・赤を入れる・返す・足す）。抽象的な言い回しは使わない。
- 「〜できていない」ではなく「〜に時間がかかっている」「私がやってみて」と言う。
- 数字は 2 つまで（生徒数と「3か月後に報告」）。
- 専務の顔を見て話す時間を作る。動画のあと、実演のあと、お願いのあと。
- 答えられない質問は「持ち帰って確認します」。
