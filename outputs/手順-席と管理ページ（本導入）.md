## 毎日（10-01 から）

- 科目やクラスが変わる家庭には「tube study の設定から、クラス・受講科目を変えてください」と伝える（メールなど）。保護者が自分で直す。
- 全体は管理ページで見る：「生徒」タブ（クラスごと・ID でさがす）、「いまの様子」の「最近の動き」（だれが登録し、何を変えたか）。
- まちがっていたら、管理者が直せる（その ID の「ほか」→「学年・クラス・科目を変える」）。
- 知らない ID は「在籍終了にする」。**退塾の連絡は要らない**：本番に切り替えたあとは、3か月使われない ID は、記録と写真ごと自動で消える
  （「いまの様子」→「使われていない口座」に、2週間以内に消える ID が出る。続けて使う生徒なら、一度入ってもらえば消えない）。
- **組分けテストの日程を入れる**：「いまの様子」→「組分けテストの日程」→ テストの日を「足す」。テストの7日後から2週間、生徒のホームに
  「クラスは どちらに なりましたか」が出て、本人（保護者）が答える。答えた人数は同じ所に出る。日程を入れなければ、何も聞かない。
- **新年度のはじまり**：「いまの様子」→「新年度のはじまり」に、切り替えの日を入れる（あした以降の日）。その日の朝に、全員の学年が1つ上がる。
  中3は卒業（クラスから外れる）。小6→中1 は、ホームで本人がクラスを答える。まだ答えていない人数は、同じ札に出る。
- **対面で宿題を見るとき**：生徒にノートの各ページの上へ ID を書かせる。講師は「宿題チェック」→「対面で採点」→ その ID の帯を左右になぞる（離したところの数が付く）。

## はじめにやること（上から順に）

1. **表を Google スプレッドシートに取り込む。** drive.google.com →「新規」→「ファイルのアップロード」→ `合言葉の表.nosync/…xlsx` → 開く。
   共有は「制限付き」のまま。表に名前を書かない。取り込めたら、この Mac の .xlsx は消してよい。
2. **反映する。** `sh deploy/更新.sh`（束も送って入れる。何度流しても同じ。デモも、サーバを止めずに作り直す）。
   束が入らなかったときは、最後に「⚠ 席の束が入っていません」と出て止まる（そのときは、カードの ID ではまだ入れない）。
3. **管理ページに入る。** `https://tube-study.uk/admin` に、表の「講師と管理者」タブの `wadmin01` の行で。
   入ったら「講師と担当」→「管理者を足す」で、2人目を作っておく（1人が入れなくなっても続けられる）。
4. **担当を決める。** 「講師と担当」→ コースの行で講師を選ぶ（か、講師の札を開いてコースを押す）。

## 配る

### 対面の生徒・講師 ―― カード
1. 表から、配りたい行（番号・ID・合言葉の列）をコピーする。
2. 管理ページの「カード」に貼る →「カードにする」→「刷る」（A4 に10枚。点線で切る）。
3. 渡す。**QR をカメラで読むと、入口が開いて、そのまま入れる。** 手で打つときは ID と あいことば（線を入れなくても、大文字でも入れる）。
4. 刷り終えたら「消す」。

### オンラインの生徒・離れた所の講師 ―― 1回だけ使えるリンク
1. 「席と合言葉」→ クラス → その席の「ほか」→「オンラインで渡す」。リンクが1回だけ出る。
2. 「送る文をコピーする」（説明つき。リンクだけなら「リンクだけコピーする」）→ メールや授業のチャットで、本人に送る。
3. 本人がリンクを開くと、**本人の端末の中で本物の合言葉が作られ**、画面に1回だけ出る（書きとめてもらう）。そのまま入れる。
   - リンクは1回だけ・7日まで。リンクにも、メールにも、サーバにも、合言葉は載らない。
   - 本人が「開いたけれど入れない」と言ったら、先にだれかが開いている。もう一度「オンラインで渡す」（前に引き換えた人は、その場で入れなくなる）。
   - 席の行に「引き換え待ち（○/○ まで）」→ 引き換えると「使っている・引き換えた日」。

### 名簿に出るとき
- カードやリンクで**本人がはじめて入ったとき**、その席は講師の名簿に出て、宿題を受け取る。**そのとき出ている宿題（期限前）も、その場で届く。**
- **紙だけの子・対面の子**（アプリに入らない）は、管理ページで「使う」（「1番から○番までをまとめて使う」もできる。2度押し）。
- まちがえて「使う」にした席は、「ほか」→「渡していないに戻す」（写真や評価がまだ無ければ戻せる）。
- 渡していない席は、どこにも出ない。

## 毎日の使い方

- 「いまの様子」のいちばん上に、次にやることが1つ出る（まだ見ていない報告／授業計画の無いコース／講師の決まっていないコース…）。
- 合言葉をなくした → その席の「ほか」→「合言葉を作り直す」（紙で渡す）か「オンラインで渡す」。前の合言葉と、開いていた画面は、その場で使えなくなる。
- やめた生徒 → 「在籍終了にする」（入れなくなり、記録は残る）。渡していない席は「消す」。
- 席が足りない → クラスを開いて「あと○席 足す」。
- **クラス替え（5週ごと）** → 「席と合言葉」の学年の見出しの「クラス替え」→ 行き先を選ぶ →「確かめる」→「移す」。ID・合言葉・記録は変わらない。まちがえたら「取り消す」。
  移った生徒の出席番号は、行き先のクラスで空いている番号になる（まだ渡していない席・在籍を終えた生徒の番号は取らない。30席あるクラスなら 31番から）。ID は前のまま。
- クラスを足す（講習など）→ 「席と合言葉」のいちばん下の「クラスを足す」。コースは「講師と担当」→「コースの表を直す」。
- うまく動かないとき → 生徒も講師も、右上のメニュー「うまく動かないとき」。管理ページの「報告」に集まる。
- 「報告」に「入口の見張り」が出たら → そこに並んだ ID に、まちがった合言葉が続けて届いて、その所からは15分ほど入れなくなっている。本人なら待てば入れる。合言葉をなくしていたら作り直す。「どこからも」と付いた ID は、あちこちからたたかれている（続くようなら Cloudflare で止める）。
- 管理ページは、さわらないと30分で切れる（開いたままでも）。入り直せば続きから。

## 本導入の前に、実機で1回ずつ（機械では Chrome・Edge・WebKit〔Safari のエンジン〕で確かめた。Safari のアプリと iPhone は目視）

- **iPhone の Safari で、初回登録を1回**（登録コードの QR から）：動画が流れるか／合言葉を作るときに「パスワードを保存しますか」が出るか／
  出て入り直すときに、Face ID で ID と合言葉が自動で入るか。**ここだけは機械で確かめられていない**（Safari のアプリの部品）。
- iPhone で、講師として「宿題チェック」→「対面で採点」：帯を指でなぞって数が付くか（縦に巻けるか・横になぞっても画面が戻らないか）。
- Mac の Safari で：管理ページに入る／「講師と担当」の選ぶ部品の大きさ／配る紙を刷る。
- 動く下限は **iOS・Safari 16.2**（2022年12月）。それより古い iPhone（7 以前）は色が抜ける。保護者への案内に「iPhone は iOS 16.2 以上」と書く。

## 作り直すとき（反映の前だけ）

**一度も iCloud に載っていない合言葉にしたいとき**は、反映（`更新.sh`）の前に限り、作り直せる。

1. `合言葉の表.nosync/tubestudy-合言葉の表-waseaca-london.xlsx` と `deploy/accounts/waseaca-london.bundle.json` を消す。
2. `python3 scripts/accounts/make.py`（同じ 521件を、新しい合言葉で作る）。
3. 上の「はじめにやること」を 1 から。

**反映したあとは、作り直さない**（サーバの値と表が食い違う。道具も止める）。あとからは、管理ページで1人ずつ。

- 合言葉の表を持つ Google アカウントは、2段階認証に。
- デモは `https://tube-study.uk/demo` に移る（本物の校舎を入れたあと、ふつうの入口には「ためしに見る」が出ない）。デモごと止めるなら `DEMO=0 sh deploy/更新.sh`。
