# 批評 ―― 早稲アカOnline に対して、tubestudy は何に負け、勝てるものが本当にあるのか（2026-09-14）

前提を正直に置く。**専務の評価は的を射ている。** 「早稲アカOnlineとやれることはほぼ同じ」「チンケなマクロ」は、
組織の側から見れば正しい。ここでは言い訳をせず、いちばん厳しい視点で切る。

---

## 0. 早稲アカOnline とは何か（公開情報で確認できる範囲）

早稲田アカデミーの生徒・保護者向け公式ポータル。公開されている機能は次のとおり。

- 直近のスケジュール表示、双方向Web授業への参加ボタン、校舎への遅刻・欠席連絡（授業20分前まで）
- 校舎からのお知らせ（未読・発信元・カテゴリで絞り込み）
- 各種Webサービスへの入口（学習サービス、成績帳票サービス）
- 成績の確認（直近の模試、過去年度の一覧、模試ごとの詳細）
- 2022年12月に「模試成績表示」を追加。「情報の共有 ⇒ 授業への参加 ⇒ 努力の成果の確認」という流れを掲げている

つまり早稲アカOnline は **「校舎と家庭の公式な窓口」＋「模試の成績帳票」** である。
公開情報の範囲では、**宿題の写真提出・講師の評価・添削の返却・単元ごとの理解度・個別の宿題** は無い。

（出典：[早稲田アカデミーOnline 公式](https://www.waseda-ac.co.jp/waseda_online/)、[プレスリリース 2022-12-16](https://prtimes.jp/main/html/rd/p/000000024.000051025.html)、[App Store](https://apps.apple.com/jp/app/%E6%97%A9%E7%A8%B2%E7%94%B0%E3%82%A2%E3%82%AB%E3%83%87%E3%83%9F%E3%83%BConline/id1581525554)、[オンライン校サポート](https://www.waseda-ac.co.jp/online_school/support/)）

## 1. いただいた5つの意見は、それぞれ何を言っているか

| 意見 | 本当の意味 | 反論できるか |
|---|---|---|
| ワーホリの人に任せるのはリスクしかない | 「誰が保守するのか」ではなく「**組織が依存してよい相手か**」の問題。文書があっても解決しない | できない。個人が作ったものを組織が採用しない理由として正しい |
| すでにワセアカOnlineで全部できている | 組織が必要とする層（お知らせ・出欠・模試成績・保護者窓口）は**すでに満たされている**。tubestudy が扱う「授業の中の日々の宿題」の層は、組織の側から見れば **必要とされていない層** | 半分だけ。機能は重なっていない。しかし「必要かどうか」を決めるのは組織であり、その答えは「要らない」 |
| 講師の負担が増えるのでは | 新しい道具は最初は必ず負担を増やす。減る根拠は私の主張しかない | できない。証拠が無い |
| 使わない講師・教科への批判になるのでは | **見えなかったものが見えるようになる**ことへの警戒。曖昧さが組織を守っていた | できない。これは道具の問題ではなく、組織の文化の問題 |
| 宿題を管理させるのは正義か | 宿題の扱いは講師の裁量。tubestudy は「宿題は管理すべき」という**規範**を持ち込む | できない。私は道具を売っているつもりで、規範を売っていた |

5つのうち、機能の話は1つも無い。**全部「誰が・何を決めるか」の話**である。
ここを機能で返そうとしたのが、今回の敗因。

## 2. 圧倒的に負けているもの

| 項目 | 早稲アカOnline | tubestudy |
|---|---|---|
| 正統性 | 会社の公式システム | 一講師の私物 |
| 継続性 | 会社が保守。担当が辞めても続く | 私が居なくなれば止まる |
| 規模 | 全校舎・全生徒・全保護者 | ロンドン校の私のクラス |
| 統合 | 模試・スケジュール・出欠・請求・お知らせが一つ | 宿題だけ。他と繋がらない |

| 法務・個人情報 | 会社の規程と法務部が担保 | 私の設計を信じてもらうしかない |
| サポート | コールセンター | 私 |
| 費用 | 払い済み | 無料だが「無料の理由」を疑われる |

## 3. 「勝っているところ」は本当にあるか

機能としては、早稲アカOnline に無いものを持っている。

- 紙の宿題を写真で出し、講師が1〜5で評価し、iPad で赤を入れて返す
- 単元ごとの理解度が、日々の宿題から積み上がる
- 理解度から、一人ひとりに宿題を足す／減らす
- 苦手から出る毎日テスト
- 続けた記録・目標（生徒の側の動機づけ）

だが、厳しく言えば **「機能がある」と「価値がある」は別**。

- これらの機能が価値を持つのは、**組織が「日々の宿題の出来」を経営上のデータとして欲しいとき**だけ。今の早稲アカはそれを模試と確認テストで足りるとしている。
- 「早稲アカOnline に無い」は強みではない。**会社が作ろうと思えば四半期で作れる**。作っていないのは「要らない」と判断したから。
- オンラインの生徒への「印刷→赤→スキャン→メール」を無くすのは本当の痛みだが、それは**校舎の一部の講師の**痛みであって、会社の痛みではない。

結論：**組織を買い手とする限り、勝っているところは無い。** 勝っている機能は、別の買い手（後述）に対してだけ意味を持つ。

## 4. 「チンケなマクロ」は当たっている ―― 何がマクロで、何が本質か

tubestudy がやっていることは「集める・見る・返す・記録する」の自動化である。
**教え方も、教材も、生徒が学ぶ内容も変えていない。** 既存の作業の周りを回しているだけ。
それは個人の生産性道具（＝マクロ）であって、組織の仕組みではない。

私自身の反省として、プレゼンを「仕組み化」「手間はへる」で組んだことが、
この評価を招いた。**組織のシステムとして売り込めば、組織のシステムと比べられる。** 当然の帰結。

では本質は何か。巨大な塾会社にとって意味のあるものは、次の3つしか無い。

1. **退塾を減らす**（売上の大半は継続で決まる）
2. **合格実績を上げる**（ブランドの源泉）
3. **講師の質を、人に依存せず保つ**（拡大と海外校の制約）

早稲アカOnline はこの3つに直接は効かない（窓口と帳票だから）。
tubestudy が本質に踏み込めるとしたら、**日々の宿題の出来という「日次の信号」** がこの3つに効くと示せた場合だけである。

- 提出が途切れる → 数週間後に退塾、という**先行指標**になりうる（模試は月単位で遅い）
- 単元ごとの理解度 → 合格実績に効く**個別最適化の根拠**になりうる
- 「誰に何を出すか」を仕組みが提案する → **経験の浅い講師でも上位講師と同じ判断**ができる（海外校の講師は短期で入れ替わる）

これらは仮説であり、**証拠は一つも無い**。証拠が無い仮説を、証拠を持つ組織の判断に対して主張した。負けて当然だった。

## 5. 本質に踏み込むための、三つの道

### 道A ―― 買い手を変える
この製品の本当の買い手は「講師が決裁者である塾」＝個別指導塾・小規模塾・海外の日本人塾。
そこには公式ポータルが無く、宿題の層こそが日々の価値になる。
ただし、早稲アカの講師である間は**利益相反**になる。ロンドン校の役に立ちたいという当初の目的とは別の道。

### 道B ―― 組織の「欲しい」を変える（証拠で）
自分のクラスだけで、私物の道具として使い、**数字を取る**。
提出率、返却までの日数、記述の評価の推移、そして「提出が途切れた子がどうなったか」。
3か月後に「お願い」ではなく「結果」を持っていく。
ただし、専務の5つの意見のうち「継続性」と「文化」は数字では解けない。数字は入口を開けるだけ。

### 道C ―― 所有を手放し、考えを渡す
tubestudy を採用してもらうことをやめ、**「宿題の写真提出と添削の返却」を早稲アカOnline の機能として提案する**。
本部のシステム部門に、仕様と、ロンドン校での試作の記録を渡す。私は何も得ないが、
「お金や契約は関係なく、ロンドン校の役に立ちたい」という目的には、いちばん忠実な道。
継続性・正統性・保護者の混乱・講師間の不公平、**5つの意見がすべて消える**のはこの道だけ。

### 勧め
**B と C を同時に。** B で自分のクラスの数字を3か月取り、その数字を添えて C を出す。
A は、早稲アカを離れるときに初めて考える。

## 6. いま直すべきこと（機能ではない）

1. **売り文句を全部捨てる。** 「仕組み化」「手間はへる」「先生の時間を授業へ」は、組織のシステムとして比べられる言葉。使わない。
2. **保護者の画面を封印する。** 公式アプリと並ぶ2つ目の窓口は、会社が最も嫌うもの。数字を取る期間は講師と生徒だけ。
3. **他の講師に見えないようにする。** 私のクラスの中で閉じる。「使わない講師への批判」を構造的に不可能にする。
4. **測るものを決めてから使う。** 提出率／返却日数／記述の評価の推移／提出の途切れと、その後。この4つだけ。
5. **本部への提案書を1枚書く。** 「早稲アカOnline に宿題の写真提出と添削返却を足すとしたら」。仕様は tubestudy のものをそのまま渡す。

## 7. 一枚で言うと

> 機能では負けていない。**買い手を間違えた。**
> 組織は「宿題の層」を欲しがっていないし、個人が作ったものに依存しない。
> 本質に踏み込むなら、「宿題の日次データが退塾と合格に効く」と**証拠で**示すか、考えを組織に渡すか。
> どちらも、道具を売り込むことではない。

## 8. 追記 ―― 対面の生徒と「判断は講師の仕事」（2026-09-14 夜）

さらに二つ、当たっている指摘。

1. **対面の生徒は、紙でその場で直して、その場で返している。** 写真に撮って、アプリで評価して、返す方が遅い。
   つまり宿題チェックの価値は「対面」では**マイナス**。残るのはオンラインの生徒と、持ち帰って直す記述・作文だけ。
2. **できる子・できない子を見分け、理解するのは講師の仕事そのもの。** それを「グラフで見える」「押すだけ」と
   簡便化して見せるのは、講師の職能を取り上げて見せているのと同じ。弱いのではなく、**逆効果**。

この二つを引くと、講師向けの価値はほぼ残らない。残るのは次の三つだけ。

| 残るもの | 誰の価値か | 講師の判断を侵すか |
|---|---|---|
| オンラインの生徒の添削ループ（写真 → iPad で赤 → 返す） | 講師（オンライン担当だけ） | 侵さない（返し方が変わるだけ） |
| 生徒が自分の間違いを記録し、そこから復習が出る（毎日テスト・やり直し） | **生徒** | 侵さない（講師は何もしない） |
| 担当が変わっても、生徒ごとの記録が残る | 組織（将来） | 「記録すべき」という規範を持ち込む。今は求められていない |

### 本質は「講師」ではなく「生徒の自習」にあった

集団塾は、授業と授業のあいだを生徒と家庭に任せている。
講師がその場で直すのは授業の中の話で、**家に帰ってからの復習は誰も見ていない**。
早稲アカOnline も講師も、ここには居ない。個別指導塾は、ここを人（高い）で埋めている。

ソフトが人より強いのは、ここだけである。
- 自分が間違えた問題を、忘れる頃にもう一度出す（間隔反復）。人にはできない量と頻度。
- 教材の中身は持たない。「教材名・ページ・問題番号・正誤」だけで回る（教材データを置かない設計と一致する）。
- 講師に何も要求しない。「宿題を管理しない講師」がいても成立する。
- 講師の判断（できる子・できない子）を、代わりに下さない。生徒が自分の間違いに向き合うだけ。
- オンライン・海外の生徒ほど効く（自習室も、隣の席の友だちも無い）。

つまり tubestudy を「講師の道具」から「**生徒の復習の仕組み**」に置き直すと、
専務の5つの意見のうち、負担・不公平・正義の3つが消える。残る継続性と正統性は、
道C（考えを渡す）か、**塾を買い手にしない**（生徒と家庭が自分で使う道具にする）ことでしか消えない。

### 次に問うべきこと
- 生徒の復習の仕組みは、早稲アカのカリキュラム（単元の並び）に沿うだけで成立するか。→ 成立する（教材の中身は要らない）。
- それは早稲アカOnline と競合するか。→ しない（層が違う）。競合は Anki・Quizlet・映像教材の類。
- 講師が一切触らなくても、生徒は使い続けるか。→ **ここが未検証。** 検証しない限り、また同じ負け方をする。

## 9. 追記 ―― 混在・「全員の成績を把握する必要があるか」・システムのための手間（2026-09-14 深夜）

**結論から。価値よりも、リスク・持続性・展開のしにくさの方が勝つ。** 今の形で早稲アカに入れる理由は無い。

| 指摘 | 正直な答え |
|---|---|
| クラスに対面とオンラインが混在している | 一部の生徒だけに道具を当てると、**1つのクラスに集め方・返し方・記録が2通り**できる。混在は「部分導入」の最悪の形。全員を写真にすれば対面の子の手間が増え、オンラインだけにすれば講師の作業が二重になる。クラスの作業に触る道具である限り、逃げ道が無い |
| そもそも全員の成績を把握する必要があるか | 無い。集団塾のクラス分けと進度は模試と確認テストで足りる。単元ごとの細かい把握が価値を持つのは、**その情報で誰かが生徒ごとに動くとき**だけ。集団塾にはその人手が無いので、データは溜まるだけで使われない。「データに残る」は価値ではなく在庫だった |
| システムのために手間が増える | その通り。撮る・上げる・押す・ひとことを書く・お知らせを見る。生徒が学ぶ中身は一つも変わらないのに、講師の1人あたりの分数は増えた。「記録が残るから」で正当化する道具は、道具のための道具 |
| 価値に対して、リスク・持続性・展開のしにくさが勝つのでは | 勝つ。証拠のある価値がゼロで、個人情報と依存のリスク、一人開発の持続性、混在クラスと講師のばらつきという展開の壁は、それぞれ**単独でも**採用を止める理由になる |

### それでも残る形は二つだけ
1. **クラスの作業に一切触らない、生徒が自分で使う復習の道具**（正誤だけ。写真も評価も保護者も無し）。塾のシステムではなく、Anki や単語帳アプリと同じ立場。塾に依存も要求もしない。
2. **考えだけを本部に渡す**（早稲アカOnline に「宿題の写真提出と添削返却」を足す提案）。私の手を離れるので、継続性と正統性の問題が消える。

そして、**やめる**も正当な選択肢である。ロンドン校の役に立つ道が、この道具ではなかったと分かったのが今回の収穫。

### 早稲アカの中で 1 を試すなら
専務の反応のあとなので、「個人的におすすめのアプリ」として生徒に勧めるのも、勝手に見える。
校長に「写真も評価も保護者も無し、生徒が正誤を入れるだけ、希望者だけ、4週間」と伝えて了解を取る。
了解が出なければ、早稲アカの中では何もしない。
