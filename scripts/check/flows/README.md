# 流れの検査（画面を実際に押して確かめる台本）

2026-10-01 に、一時領域にしか無かった台本をここへ移した。**expect.py が「数が合っているか」を見るのに対し、ここは「押したらそうなるか」を見る。**
ブラウザは Chrome・Edge・WebKit（Safari のエンジン）のどれでも流せる（`TUBE_BROWSER`。`../README.md`）。

## 使い方
    S=/tmp/tube-flows; mkdir -p $S
    rsync -a --exclude .DS_Store --exclude '*.nosync' "…/tube-schools/app" "…/tube-schools/server" "…/tube-schools/scripts" $S/tube/
    sh $S/tube/scripts/check/flows/run.sh $S                      # Chrome だけ（12分ほど）
    sh $S/tube/scripts/check/flows/run.sh $S chrome edge webkit   # 3つとも
    # 1本だけ：土台を作り直してから流す
    sh $S/tube/scripts/check/flows/reset.sh $S && TUBE_BROWSER=webkit python3 $S/tube/scripts/check/flows/adm_flow9.py $S

iCloud の上では流さない（遅い。`MYACADY_ROOT` を作業の場所に向けるので、本物のデータには触れない）。巡回やサーバの検査と同時に流さない。

## 足すとき
- 新しい画面を作ったら、台本を1本足す（`adm_flow<次の数>.py`）。頭の形は既存のものを写す（`S = sys.argv[1]`・`from cdp import Chrome`）。
- ブラウザを2つ同時に開く台本は、`port=` を別々に（WebKit では使わないが、Chrome・Edge で要る）。
- 画面が変わる途中で撮ると、重なった絵になる（切り替えの動きは 0.4秒ほど）。撮る前に待つ。
- 「日がたったら」は、サーバの時計を動かさず、関数に `now=` を渡す（`retire.roll(T, school, now=…)`）か、口座の `used`・`created` を書き換える。
