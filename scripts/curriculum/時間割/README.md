# 時間割（2026-10-08）

ロンドン校の時間割。元は **`カリキュラム/時間割.csv`**（1行＝1コマ。表計算で開いて直せる）。
講師の名字が入るので、`時間割.csv` と `時間割.json` は本番へ送らない（deploy で除外）。

## 直し方
1. `カリキュラム/時間割.csv` の行を直す（または Claude に「〇〇を△△に」と言う）。
   列：曜日・教室（A〜E、未定は ?）・開始・終了・授業・講師・コース（クラス:教科。2つなら空白区切り）・印・注
   印：訂正／新規／仮（本人が「たぶん」「一旦」）／要確認／時間変更／外した（記録として残し、時間割からは外す）
2. `python3 scripts/curriculum/時間割/build.py` … 次の3つを作り直す
   - `カリキュラム/時間割.json`（機械が読む形）
   - `カリキュラム/コマ.csv`（システムへ入れる時間だけの表。講師名なし）
   - `Claude outputs/時間割の確認.html`（照らし合わせ用。重なりと要確認を自動で出す）
3. 本番へ入れる：`sh deploy/時間割.sh`（変わるコースを出してから、入れてよいか聞く）。入るのは時間だけ。
   講師・受ける生徒・授業計画は管理ページで決めたものがそのまま残る。
