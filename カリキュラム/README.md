# カリキュラム ―― 第一信頼情報源

ここにあるものが、TUBE study のカリキュラム（単元の並び・テスト・日程）の**出どころ**。
サーバもデモも、ここから読む（`server/curriculum_source.py` の1本の口）。ほかの場所に写して持たない。

## 中身
| もの | 何か |

| `カリキュラム.json` | 原本を機械が読める形にしたもの。**サーバが読むのはこれ。** 鍵は英語、値は日本語。 |

## どう作ったか
PDF は文字情報の無いスキャン。macOS の Vision で3通りに読み（2倍・3倍・右半分4倍）、多数決で表を起こし、
読めなかった所と疑わしい所は画像を切り出して目で確かめた（道具・途中の読み取り・手直しの一覧は `scripts/curriculum/`）。
作り直すときは `python3 scripts/curriculum/組み立て/compose.py` のあと `render.py`。

## 形（カリキュラム.json）
- `elementary.e4|e5|e6` … 予習シリーズの回の表。`terms.first/second.subjects.<教科>[{n, unit, words?, review?, contents?, words_contents?}]`。`review` は総合の回。`contents` は各回の詳しいページの「■学習内容」の見出し（1回読み・未校正。抜けは `contents_note`）。小4・小5は `tests`（本部のテスト日程。日付の無い行は範囲の欄の回）。小6の `terms.second` は後期の学習（社理の回表、算数の下N回、週別の予定）。
- `k.classes.5K|6K.<教科>` と `k.english.year1|year2` … 5K/6K の年間の回（1〜36）。
- `junior.j1|j2|j3.classes.<クラス>.<教科>.terms[{term, units[{n, unit, test?, prep?, tasks_raw?}]}]` … 中学の【カリキュラム】表（期ごと）。英数国の `test`（単語・漢字・確認テストの範囲）は表の形で確かめた。理社の `tasks_raw`（テスト・復習課題・予習課題）は**読み取りのまま・未校正**。
- `goals_raw`（中学・5K6K の各頁）… 授業の目的・教材・授業進行・宿題の目安の文。**読み取りのまま・未校正**（PDF の該当頁が正）。
- 小学部の「学習の進め方」「テスト要項」の文、年間スケジュール、本部の授業カレンダー（前期・後期）は入れていない（PDF と `scripts/curriculum/読み取り/` を見る）。

### 確かさの段階
| 段階 | どこ |
|---|---|
| 校正済み（読み取りの多数決＋割れた所は画像で確認） | 単元名（`unit`・`words`）、期の回数、総合の回、テスト日程、ロンドン後期日程表、小6後期の表 |
| 1回読み・未校正（字の小さな落ちがありうる） | 小学部の `contents`・`words_contents` |
| 読み取りのまま（使う前に PDF で確かめる） | 中学理社の `tasks_raw`、`goals_raw` |
- `london.second_2026` … 後期日程表（週ごとの水・土・日・月、授業の週 `lesson_weeks`、テスト、休み）。
- `london.classes` … ロンドンの78コース（クラス:教科）ごとに、どの表と週の並びを使うか。`table` が null は対応なし（理由は `note`）。
- `london.syllabi` … 表と日程表から**週に並べたシラバス**（`server/syllabus.py` の形＋ `perWeek`・単元ごとの `week`）。サーバはこれを読む。

## 決めたこと・仮定（要確認は本人へ）
- 日程表の「四谷大塚（下）…第N回」「N月通常授業①」「休校日」は、月〜金をまたぐ**週の帯**（その週の授業の回）。授業の曜日はクラスごとで、その週の授業日に置く。
- 小学部（小4・小5・小6）の週は、その帯の「第N回」そのもの。小4・小5は 8/31の週＝第2回 … 1/17の週＝第19回。小6は 9/7の週＝第1回 … 1/17の週＝第14回で、合判対策の週（8/31・10/5・11/9・11/30 の週）が入る。
- 授業の無い週（10/26〜30 ハーフターム、12/21〜1/1 冬期講習会、1/25〜2/5 休校）は、授業日を作らない。
- 週2コマのコース（例：中3R 数学）は、その週の単元を2コマとも当てる（2つ先へ詰めない）。
- 中学部は「9月通常授業①（8/31の週）＝本部の2学期①、以後は通常授業の週に1回ずつ（冬期講習会の回も順に）」（2026-10-08 本人に確認）。数学3T は本部が週2回なので週に2つ。
- 5K/6K は「9月通常授業①（8/31の週）＝第17回」。6K は本人に確認（比の単元＝第17回「比①」から）。5K は同じ年間カレンダーなので第17回と置いた（**本人に未確認**。画面に「週の合わせ方は仮」と出る）。
- 中学の D クラス（j1d・j2d）は R の表（2026-10-08 本人）。中1D 国語・数学は 1R、中2D 国語は 2R、中2D 数学は 2R1。
- 小4〜小6の英語、O・難プロ・土特・講習会の類は原本に表が無く、対応を決めていない。
- 小4K（e4k）は日程表の小学部・中学部のどちらにも書かれていない。部が分からないので、原本の組分け（小学部）は当てない。
- 小6後期の国語は回の名前が原本に無い（`予習シリーズ6年下 第N回` と置いた）。算数の第1回も無い。
- 読み取りの癖で `説明文章`→`説明的文章`、`文学文章`→`文学的文章` にそろえた。
- 後期日程表は原本に「仮日程」とある。土曜の 12/13・1/31 は原本の表記で、実際の土曜は 12/12・1/30。
- 小4・小5のテスト日程で、表に名前の無かった4か所（1/16, 9/12, 10/17, 12/5）は前後の並びから「カリキュラムテスト」と補った（`filled`）。

## サーバでの使われ方
- `server/curriculum_source.py` が唯一の読み口。`syllabus.py`（コースのシラバス）・`reference_curriculum.py`（学年の本部基準）・`exams.py`（組分けの既定）・デモがここから読む。
- 優先の順：`shared/` に取り込んだもの ＞ この JSON ＞ `server/syllabus/` の仮置き（いまは無い）。ただし shared の**仮の印の付いた**本部基準は、この JSON がある学年では使わない。
- 組分けの既定：`exams.json` に日程が一度も入っていない校舎では、日程表の「組分け・月例」（小学部）を使う。中学部・5K6K の生徒には当てない。管理ページで外せば空のまま。
- 進み具合：計画がこの JSON のシラバスから組まれたコースだけ差を数える。講師が画面で作った計画は、単元名が合う行だけを数え、1つも合わなければ差を出さず「今週の本部の予定」だけを出す。
- 学年の本部基準（`reference`）は、学年の教科ごとに最初に対応したクラスの表から作る（中1国語なら 1T）。表の無いクラス（D など）はこの学年の基準と比べる。
- 本番へは `deploy/更新.sh` が JSON と文書だけを送る（PDF は送らない）。
