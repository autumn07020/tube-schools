# 紙の宿題 ―― 取り込む・分ける・採点する・返す（2026-09-24）

紙の宿題（ほとんどはノート）を、撮った PDF から生徒ごとに分けて tubestudy に入れ、
採点して、赤を入れた答案を返す。**対面の子の紙も、オンラインの子の写真も、同じ列で同じように扱う。**

- tubestudy の外に置く、別の小さな仕組み。画面と、tubestudy の口を取り次ぐだけの中継（`relay.py`）でできている。
- tubestudy から見れば「先生が画面で取り込み、評価し、返した」のと区別が付かない。**tubestudy の記録と配達をそのまま使う。**
- 構想と比べた案：`../Claude outputs/構想-紙の宿題の取り込みと採点.md`（案A・B・C を作った。案D は作っていない）。

---

## 1. 今すぐ使う（この Mac で）

```sh
sh 紙の宿題/起動.sh
```

Safari で `http://127.0.0.1:8940` を開き、tubestudy の講師の ID とパスワードで入る。止めるときは control + C。

- iPad から試すときは `sh 紙の宿題/起動.sh ipad`（同じ Wi-Fi。出てきた `http://〜.local:8940` を iPad の Safari で開く）。
  **iPad とこの Mac のあいだは http://（暗号化されない）** なので、家の Wi-Fi で試すときだけにする。
- 校舎で毎日使うなら、HTTPS の置き場に置く（§3）。

### はじめに1回
1. 「番号シールを刷る」→ コース → 刷る。A4 の 70×37mm・24枚のシール紙に、1人1枚。
   ノート・冊子の**表紙**に1枚貼る（新しいノートにしたら、また1枚）。
2. 名前で見たいときは「名前（この端末だけ）」。名前はこの端末の中だけに置き、どこにも送らない。

### 授業のたびに
1. 集めたノートを iPad の「ファイル」（か「メモ」）の**書類をスキャン**で、表紙 → 宿題のページ → 次の子の表紙 … と続けて撮る。保存先は「この iPad 内」。
2. 「取り込む」→ コース → 回 → PDF を選ぶ → 生徒ごとに分かれたページを確かめて「〇人ぶんを送る」。ノートはその場で返せる。
3. 「採点する」→ ペンで赤、◯✕△◎は選んで叩く（数は自動）→ **1〜5 を押すと、返して評価して次の子へ**。
4. 送り終えたら、撮った元の PDF を「ファイル」から消す。

家で撮って出してもらうとき（慣れてから）：`配る紙/家で撮って出す.html` を刷って配る。生徒・保護者は tubestudy の「宿題」から、
いつもどおり写真（か PDF）で出す。先生の採点の列に、教室で集めた紙と同じように並ぶ。

## 2. 決めごと（壊さない・嘘をつかない・戻せる）

| 決めごと | どうなっているか |
|---|---|
| tubestudy の良さを崩さない | tubestudy の決まった口（§6）だけを使う。**新しい権限は作らない**（誰が何を見てよいかは tubestudy が決める）。段階（導入の段階）もそのまま効く：取り込みは 1 以上、返すのは 3 以上 |
| 名前をサーバに置かない | 表紙と区切り紙は**撮るが送らない**。答案用紙は刷った名前の欄を白で消してから送る。名前（この端末だけ）はどの通信にも入れない（検査で、tubestudy のどのファイルにも中継のログにも出ないことを確かめている） |
| 推測で生徒を決めない | 印（番号シール・区切り紙・答案用紙）の無いページは「だれ？」に置く。読めない印は読まない（検算つき） |
| 上書きしない | 生徒が自分で出した写真・前に取り込んだ紙は、既定では置き換えない。置き換えるときは前のものをこの端末に控えてから |
| 嘘をつかない | 送ったあと tubestudy から読み直し、枚数が合ったと確かめてから「確かめました」と言う。白紙・二度撮りを黙って消さない |
| 何も保存しない中継 | 中継は答案も合言葉も書かない。ログは口の名前と結果の番号だけ |
| 端末に溜めない | 送った取り込みは7日、控えは30日でこの端末から消す |

### 戻し方

| まちがい | 戻し方 |
|---|---|
| 送る前に、ページの持ち主をまちがえた | 確かめる画面でページを押し「だれの紙？」で直す・「外す」 |
| 生徒の写真を置き換えてしまった | ホームの「控えから戻す」で、置き換える前の写真を tubestudy に戻す（この端末に30日控えてある。戻すと先生の取り込みとして入る） |
| 評価・返した答案をまちがえた | 採点の画面でその子に戻り、別の数字を押す（返した答案は差し替わる）か「前に戻す」（前の評価と、前に返した答案に戻す） |
| クラス替えをまちがえた | `python3 server/tube_server.py move --undo <番号> --school london --yes`（§5） |
| tubestudy に足した直しを戻したい | `紙の宿題/控え/tubestudy-変更前-20260924/` に変更前のファイルがある（§5） |

## 3. 置き方（校舎で使う）

中継は Python 標準ライブラリだけで動く（tubestudy と同じ）。**tubestudy と同じ箱・同じ住所には置かない**
（同じ住所に置くと、tubestudy と端末の中の保存を共有してしまう）。

- 小さな別のサーバ（例：AWS Lightsail の最小。月 $5 前後・目安）に `relay.py` と `web/` を置き、
  `置き方/paper-relay.service.例`（systemd）と `置き方/Caddyfile.例`（HTTPS）で動かす。
- 住所（例 `paper.〜`）の DNS と、DPIA の処理者の表に「中継（保存しない）」を1行足すのは本人の判断。
- 反映は本人が行う（私はサーバに入らない）。

## 5. tubestudy に足した直し（クラス替え。2026-09-24）

組み分けテストのたびに α⇄β・T⇄R が入れ替わる。調べたら、tubestudy には**クラスを移す道が無く**、次が起きる作りだった：
移った生徒の「成績の伸び」から前のクラスの単元が消える／テストの日の席で書かれた表を今の席で合わせて別の生徒に点が入る／
前のクラスの成績の人数が膨らむ／空いた席に古い名簿を流すと同じ番号が2人になる。

足したもの（本人の指示「修正が必要なら確実に行うこと」による。変更前のファイルは `控え/tubestudy-変更前-20260924/`）：

- `server/tube_server.py`：`move`（確かめる → `--yes` → `--undo` → `--list`）、`class_at`・`desk_labels(at=)`・`moved_out`・`move_edges`・`score_roster`、
  `desk_roster`・`desk_board`・`student_growth`・塾内テストの取り込み・`roster-import`・`add` の直し
- `server/paths.py`：まとめて書き換える前の控えの置き場（`backups/<番号>/`、60日で消す）
- `server/test_moves.py`（64件）、`roster-tool/対応表.html`（「5. クラス替え」）、`CLAUDE.md`（クラス替えの節）
- クラス替えの記録が無いうちは、どの直しも今までと同じ動き（tubestudy の検査一式が変更の前後で同じ数だけ通る。意味の検査 212件・減り 0）

本番への反映は、いつもどおり本人が `sh deploy/更新.sh`。クラス替えの日の手順は `CLAUDE.md` の「クラス替え」の節。

戻すとき（反映する前なら、この2つのファイルを戻すだけ）：

## 6. 使っている tubestudy の口（形が変わると動かなくなる）

| 口 | 使うもの |
|---|---|
| `POST /api/login/start`・`POST /api/login/finish`（合言葉そのものは送らない。`web/js/scram.js` は tubestudy の `app/js/scram.js` の写し）・`POST /api/logout`・`GET /api/me` | 合言葉、`profile.role`・`assign`（`key`・`name`・`use`・`day`・`start`） |
| `GET /api/today` | `tasks`（`key`・`n`・`name`・`todo`） |
| `GET /api/check?key=&n=` | `course.use`・`lesson`・`lessons`・`rows`（`sid`・`label`・`head`・`files`・`origin`・`v`・`note`・`returned`・`ratedAt`・`pruned`） |
| `PUT /api/check/rate` | `{key, n, sid, v, note}` |
| `GET /api/submissions/<束の代表>/<sid>/<名前>` | 答案の画像 |
| `POST /api/submissions/<束の代表>/<sid>/scan`・`…/return` | 取り込み・返す（1人6枚・1回12MBまで） |
| `POST /api/quiz` | 提出箱を作る（答案用紙を刷るとき） |

tubestudy の側でこれらの形を変えるときは、`sh 紙の宿題/検査/全部.sh` を通す（`CLAUDE.md` にも書いた）。

## 7. つながらないとき

| 出てくる言葉 | 見る所 |
|---|---|
| 「tubestudy の証明書を確かめられません」 | 中継を動かす Python が証明書を読めていない。`SSL_CERT_FILE` に証明書の束を指すか、置き場の Python を新しくする |
| 「tubestudy から思わない返事が来ました（403）」 | Cloudflare が中継からの呼び出しを止めている。Cloudflare の設定で中継の住所を通す（本人の判断） |
| 「試行が多すぎます」 | tubestudy のログインの試行制限は相手の住所ごと（15分に30回の失敗）。中継を通すと講師全員が1つの住所に見える。15分待つ |
| 「このコースでは添削を使っていません」 | tubestudy の「導入と進度」で 3（添削まで）にすると返せる |
